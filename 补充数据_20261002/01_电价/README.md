# 01_电价 — 乌鲁木齐 / 固原 / 武汉 三场景分月代理购电电价

本目录为供热规划竞赛论文补充的电价数据包：抓取并归档**新疆（乌鲁木齐）、宁夏（固原）、湖北（武汉）**三省区的**分月代理购电价格公告/价格表**原件，抽取为可直接回填的表格。

抓取日期：2026-10-02（Asia/Shanghai）。所有原件均来自官方渠道或政府网站对官方公告的原文登载，未使用任何媒体/自媒体转述件作为数据来源。

## 3. 口径（务必先读，跨口径不可混用）

主表 `tariff_months_extracted.csv` 的 `sharp/peak/flat/valley_CNY_per_kWh` 填的是**分时电度电价（到户口径）**：

```
分时电度电价(某一时段) = 代理购电价格(该时段) + 上网环节线损(费用折价)
                       + 电度输配电价 + 政府性基金及附加 + 系统运行费折价
```

- 三省原件均可在表内用公式自校验（宁夏 `8=1+4+5+6+7`、新疆 `7=2:尖峰+3+4+5+6`、湖北 `1=2+3+4+5+6` 且 平段=非分时电度电价）。
- **不含**：容量补偿/容需量电价（另列 `capacity_fee`/`demand_fee`）、居民电采暖价（如新疆煤改电居民 0.22 元/千瓦时，属另一政策，本包未采）。
- `capacity_fee_CNY_per_kVA_month` = 变压器容量电价（元/千伏安·月）；`demand_fee_CNY_per_kW_month` = 最大需量电价（元/千瓦·月）。**单一制行原表印 `0`，表示不适用**（照录，未改写）。
- **纯代理购电价**（不含输配/基金/系统运行费的电能量成本，含分时值）见 `tables/tariff_components_monthly.csv`，列名为 `agent_purchase_price_*`。宁夏的代理购电价本身按峰/平/谷分时段给出；新疆按尖峰/高峰/平/低谷分段给出；湖北为单一均价（不分时段）。
- 政府性基金及附加：宁夏全月恒 0.021325、新疆恒 0.0041、湖北恒 0.0452（元/千瓦时）——三省均为含基金口径，跨省比较时注意差异。

**空值语义**：`sharp` 列为空 = 原表无此档或不适用 —— 宁夏原表只有高峰/平段/低谷三档（112 行全空）；新疆 2024-10、2025-02、2025-03、2025-04 按新发改规〔2023〕11号不设尖峰时段（该 4 个月 ×7 行 = 28 行空）。合计 140 行 sharp 为空，其余列无空值。

各月 `valid_from`/`valid_until` 均取自原件「执行时间」行（当月 1 日至月末），`source_url` 为该月数据的具体出处（逐月页面 / PDF 直链）。

### 分时时段划分（三省不同，建模时不可互套）

| 省 | 峰/尖峰 | 平 | 谷 | 出处 |
|---|---|---|---|---|
| 宁夏 | 高峰 7:00-9:00、17:00-23:00 | 0:00-7:00、23:00-24:00 | 9:00-17:00（谷段输配电价按 50%） | 宁发改（2023）807号、宁夏分时电价政策2023 |

## 4. 数值可信度与校验

原件形态与处理方式：

- **带文本层 PDF**（可直接提取，无 OCR 风险）：新疆 2024-11、2024-12、2025-02、2025-03、2025-04；湖北 2025-01~04（《2025年1-12月代理购电》合并 PDF 的对应页）。
- **扫描件 PDF / 图片**（需 OCR）：宁夏 16 个月（PDF 扫描）、新疆 2024-10（7 张 PNG）、新疆 2025-01（扫描 PDF）、湖北 2024-05~12（扫描 PDF，每月 1 页含两张表）。

所有 OCR 结果均按原表自带公式**逐行算术回算**，不一致即视为误读并回读原件：

| 场景 | 校验式 | 通过 |
|---|---|---|
| 宁夏 | 分时电度电价 = 代理购电价(该时段) + 线损 + 输配 + 基金 + 系统运行费 | 112 / 112 |
| 新疆 | 分时电度电价 = 代理购电价(该时段) + 线损 + 输配 + 基金 + 系统运行费 | 49 / 49 |
| 湖北 | 非分时 = 代购价+线损+输配+基金+系统运行费；峰/谷 = 基础×比例 + 输配+基金+系统运行费 | 84 / 84 |

合计 **245 / 245 行通过**。这是一项强约束（任何一位数字抄错都会破坏等式），但仍不能完全排除「多处数字同时被误读且恰好互相抵消」的极端情形；如需绝对保险，可用 `sources/` 原件逐张复核关键行。

交叉验证：新疆 2025-02、2025-03 的两个独立转载件（鄯善县政务网 JPG、温泉县政务网 JPG）与吉木萨尔县政务网 PDF 的逐项数值完全一致。

### 已知限制

1. 宁夏、湖北原件为扫描件，数值经 OCR + 算术校验，残余误读风险不为零。
2. 三省口径不可直接比拼绝对值：政府性基金及附加三省不同（宁夏 0.021325、湖北 0.0452、新疆 0.0041，元/千瓦时），且新疆低价主要来自本地电源结构与市场化购电成本，属真实价差而非口径差。
3. 本包只覆盖「工商业代理购电」类别。若论文中的供热主体适用**电采暖专项价**（居民 0.22 元/千瓦时等）或**直接参与市场交易**，需另找依据，不能套用本表。

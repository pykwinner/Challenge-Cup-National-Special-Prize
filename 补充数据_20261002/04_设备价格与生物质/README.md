## 三、检索方法与坑（供后续复用）

- **中国政府采购网 `search.ccgp.gov.cn` 被 IP 限流**（返回“频繁访问”，出口 IP 171.113.14.60），但 **`www.ccgp.gov.cn` 的文章页可正常抓取**，可改用搜索引擎定位 URL 再直抓。
- **百度**：第 1 次请求可用，之后触发安全验证；**搜狗**：约 15 次请求后出现验证码（`/link?url=` 跳转可用 `window.location.replace` 解析出真实 URL）；**必应**经本机代理返回的结果与查询完全无关，不可用。
- **可用且稳定的入口**：内蒙古 `ccgp-neimenggu.gov.cn`、黑龙江 `hlcj.hlj.gov.cn`、宁夏 `ggzyjy.fzggw.nx.gov.cn`、内蒙古公共资源交易 `ggzyjy.nmg.gov.cn`、淄博公共资源交易 `ggzyjy.zibo.gov.cn`、邯郸住建局 `zjj.hd.gov.cn`。
- `WebSearch` 工具对中文政务内容命中良好，但**其摘要有改写风险**：本包所有入表数字均已回到 PDF/网页原件逐字核对；凡只到摘要层的，已在 `来源与适用范围_补充.csv` 标为 `partial_reference` 或 `not_found`。
- 抓取脚本曾一度给 curl 加 `-k`（跳过 TLS 校验），被权限系统拦下后已还原为普通 `curl -sL`；`receipts.json` 中所有成功条目均为正常 TLS 抓取。

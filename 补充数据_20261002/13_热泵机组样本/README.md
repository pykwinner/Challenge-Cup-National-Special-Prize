# 13 热泵机组样本｜真实品牌公开性能数据

**定位**：给城镇供热规划模型替换"卡诺效率近似"提供**可回溯到原始件的真机性能数据**。
模型两个温位：**供水 45 ℃**（末端为地暖/风机盘管）与 **供水 75 ℃**（严寒大机组）。
三城档位：乌鲁木齐＝大型低温空气源 + 污水源/工业余热源；固原＝户用/小型商用 5~30 kW；
武汉＝中小型空气源 + 地源/水源。

## 四、必须知道的口径与 QC 警告

### 4.1 四类数值严格分列，不可混用

- **能效备案 ≠ 实测**：是厂家填报 + 备案机构形式审查，不是第三方实测。
- **招标门槛 ≠ 实测**：是采购文件的★要求，中标机实际性能可能正好卡在门槛上。
- **样本标称 ≠ 实测**：是最优工况下的标称值。
- **检测报告 = 实测**，现共 **152 行 / 13 份件**，其中 148 行来自欧盟 Keymark 体系（见 §2.3）；
  注意其工况为 EN 14825/EN 14511 口径，不等于 GB/T 25127。

### 4.2 三处已验证的数据质量问题

1. **备案原表单位笔误（4 行，已在 `机组类型` 列加 QC 标注）**
   江苏英泊索尔 `KFXRS-38II / 70II / 52II / 19II`：备案表把 `制热量（W）` 填成 **38 / 70 / 52 / 19**，
   但型号名义是 **38/70/52/19 kW**，且 制热量÷功率 与 COP 自洽（38÷8=4.75 ≈ COP 4.63）。
   → **判为原表单位笔误**。本表按**原表字面**折算（0.038 kW 等），**没有替它改成 kW**，
   只在 `机组类型` 加了 QC 警告。**引用前须回查备案原表。**
2. **小容量热水机 0.6~0.75 kW（4 行）是真实的**，不是笔误：
   山东中科蓝天 `KD-WS-80L`、太阳雨 `KD12-80TR5N3E1`、春风/宝鼎 `KGD18/60L`，
   备案原表写 `制热量（W）= 600/650/750`，与一体式小热水器相符。**保留不动。**
3. **美的欧盟机型 COP 6~9（8 行）是真实样本值，但工况不适合供暖建模**：
   出自 `Mars`/`AquaThermalSuper` 欧盟产品参数表，COP 对应 **C condition (7 ℃)** 与 **D condition (12 ℃)**，
   属于欧盟 ErP 的**暖工况**口径。做三城冬季供暖模型时**不要直接套用**。

## 七、怎么用（给建模的同学）

1. **先按 `数据性质` 分层**：做基准情景用 `样本`（724 行）；做合规下限用 `招标门槛`（109 行）；
   做官方口径用 `能效备案`（4081 行）；做实测校核用 `检测报告`（152 行，其中 148 行是 EN 14825 口径，须换算）。
2. **要二维表**就在 CSV 里按 `型号` 分组，取 `源侧温度_C`/`出水温度_C` 两列都非空的行；
   真二维共 **73 台 / 575 点**。若要**开箱即用**，直接筛 §6.1 那 **270 点**
   （五者齐全 + 源侧 −20~+7 ℃ + 出水 35~55 ℃），无需任何推算。
3. **45 ℃ 温位**：数据充足（大量 41/45/55 ℃ 出水档）。
4. **75 ℃ 温位**：**这是最大的缺口**。空气源侧没有品牌二维样本；能用的只有
   ①CO2 机组标准编制汇总表（85 ℃ 档）、②汉钟 70 ℃ 螺杆水源机 5 行、③招标文件里的
   −25 ℃/≥50 ℃ 出口水温 COPh 门槛条款（如北京房山 2022：−25 ℃ COPh>1.6、−30 ℃ COPh 1.4）。
   若模型强依赖 75 ℃，建议**保留卡诺近似做敏感性上界**，或改用 55 ℃ + 末端加温的方案另做说明。
5. **别跨件拼机器**：每行的制热量/功率/COP 都来自同一份件（见 `来源文件`/`source_url`），
   换机器时请整行换。

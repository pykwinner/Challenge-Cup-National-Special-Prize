格力空气源热泵采暖机组：-35℃低温制热，60℃高温供水

格力火凤凰系列空气源热泵采暖机组专为住宅设计，具备 - 35℃低温制热与 60℃高温供水能力，可满足地板采暖、暖气片等多末端需求。机组采用直流变频压缩机、智能水路防冻检测等核心技术，支持静音 / 外出 / 节能等多种模式，搭配手机远程控制功能，兼具高效性能与便捷操控，结构紧凑易安装，为别墅、复式楼等空间提供全天候舒适采暖解决方案。

强劲制热，舒适用水

-35℃低温制热

机组选用优质零部件，保证机组在-35℃低温环境下的稳定运行，可更好的满足东北、西北、华北地区采暖空调使用。

60℃高温供水

空气源热泵采暖机组可在-35℃环境温度下提供60℃采暖热水，可在全环境工况内满足地板采暖、风机盘管、暖气片的采 暖使用需求。

宽供水温度范围

夏季可提供7～22℃冷冻水，冬季可提供30～60℃采暖热水，满足地板/吊顶辐射盘管、传统风机盘管、暖气片等 不同种类末端供冷暖所需水温，满足用户多种舒适性要求。

技术护航，安全放心

智能水路防冻检测技术

微循环水系统检测防冻技术、故障自诊断控制技术，提升机组异常情况下的防冻能力，再配合温度检测以及防冻运行控制功能，有效提升水机防冻能力，解决水路冻结问题。

多重防冻设计

多重防冻设计（水流开关+水温检测+冷媒检测），使机组在低水温、低水流量下的可靠运行，并在水系统发生故障时及时关闭主机。

功能完备，舒心掌控

多种模式满足需求

静音模式:智能划分机组运行时间段，自我调节机组输出降低机组噪音。

外出模式:为顾客冬季外出量身定制，无须拆卸机组、排空水系统等复杂操作，一键设定，方便快捷，解决外出后顾之忧。

辅热模式:留有辅热接口，增加机组低温制热量。

节能模式:针对地暖热惰性特点设计，机组自动判断进入节能模式，保证舒适性的同时降低供暖运行费用。

空调模式:以室内环境温度作为调节对象，实现水温智能跟随，舒适省心。

*注：节能模式为壁挂式机组功能；空调模式为整体式机组功能，需要选配接收板ZF33实现。

故障及时处理

机组出厂选配远程监控模块，厂内可时时监控机组运行情况，及时发现异常，提高售后异常处理效率。

手机远程控制*

使用格力+APP，可实现对机组的远程控制功能，并可随时查看机组状态。

注：该功能需要选配远程监控网关 MC31-00/C14。

多能一体，随心安装

多目标控制自主节能技术

火凤凰系列格力空气源热泵采暖设备基于室内温度的自调节控制技术，可根据用户设定室温及实际室温情况自动调节机组运行状态，实现机组全天候自动节能运行，无需用户再基于自身感觉去调节机组供水温度。

供、回水温度双温控制设计

用户可根据末端形式选择两种水温控制模式，房间舒适性更好，系统运行更加稳定。

紧凑式整体结构设计

无需单独安装水系统设备，不用为室内机位置犯愁，不影响室内装修。水路安全阀、水流开关集成机组内部，水泵、膨胀罐标配选配双选择，现场安装更简单。

无风道系统

调速直流风机、高效低噪轴流风叶；翅片底部高温流路+底盘电加热带防结冰设计

水系统

高效同轴套管换热器安全阀、水流开关标配设计，水泵膨胀罐可标配可选配

氟系统

直流变频补气增焓压缩机，双电子膨胀阀节流闪发补气系统，油分、气分标配设计

整体结构紧凑，宽度仅为427mm，高度低至1130mm，满足普通商品房安装空调要求。安装位置更灵活，普通空调平台、外墙面或其他小空间也可以安装。多能一体，舒适安心

工程设计，自由灵活

可两台空气源热泵采暖机组模块化联合，大户型住宅需求也能轻松满足。

注：同壳体机型可模块化，不同壳体机型不可模块化。GN-HRZ8~9MDGV(P)/NaA同壳体。

手拉手联动控制

采暖机组可通过简洁的手拉手式连接布线形式达到机组与温控器的联动控制， 实现对各个房间温控器开关、模式温度设定、实际温度的实时监控。

### B3 单位面积热容 / 热惰性指标 D

1. **国际标准默认值（答"80/110/165/260/370"的出处）**——⚠️ **重要更正**：
   - 这五个数**出自 EN ISO 13790:2008 表12**（"默认动态参数"：极轻80/轻110/中165/重260/极重370 kJ/(m²·K)·A_f），**不是 ISO 13786 附录A的表**。
   - ISO 13786 的角色是**计算方法**：κ_j（面热容）按 ISO 13786 第7章详细法或**附录A简化法**（ISO 13786:2017起简化法移到附录C，附录A改为输入数据模板）计算；ISO 13790 表11规定24h周期**最大有效厚度0.10 m**，C_m=Σκ_j·A_j。
   - **构造说明**（本包补上的部分）：来自 **SBi 213 / EN ISO 13790 对照表**（AAU报告附录L 表L.2，`sources/lit/aau_report_sbi213.pdf`）——极轻=仅轻质材料（木材）；中轻=少量重质材料（混凝土楼板+木/轻混凝土墙）；中=（无描述）；中重=大量重质材料（混凝土楼板+瓷砖+砖墙）；极重=仅重质材料（混凝土、砖、瓦）。该报告明确注明：**EN ISO 13790 本身未给构造描述**。
   - 数值对照（Wh/(°C·m²-floor)）：SBi213 40/80/120/160；ISO13790 22/31/46/72/103（×3.6≈80/110/165/260/370 kJ/(m²·K)）
2. **热惰性指标D（GB 50176-2016，已从原版核验）**：
   - 表3.2.2 分档：**D≥6.0 / 4.1≤D<6.0 / 1.6≤D<4.1 / D<1.6**（对应冬季室外热工计算温度 te=tw / 0.6tw+0.4te,min / 0.3tw+0.7te,min / te,min）
   - ⚠️ 与本包任务表述（">6.0 / 4.1–6.0 / 1.6–4.0 / **≤1.5**"）**不一致**：现行2016版分界是 **1.6**，没有"≤1.5"。"Ⅰ型~Ⅳ型、Ⅳ型D≤1.5"的说法见于 **GB 50176-93 版及教材/教辅**（已单列登记为文献值）。引用时请以2016版为准
   - 算法：单一层 D=R·S；多层D求和；封闭空气层D=0；非均质复合按面积加权（第3.4.8~3.4.10条）

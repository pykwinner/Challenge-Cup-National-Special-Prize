关键限值（**均为标准限值，不是实测值**）：

- 乌鲁木齐（严寒 C 区，公建）：屋面 ≤0.30、外墙 ≤0.38、架空/外挑楼板 ≤0.38 W/(m²·K)（体形系数≤0.30 档）
- 固原（寒冷 2A，居住建筑）：屋面 0.25、外墙 0.35（≤3层）/0.45（≥4层）、外窗 1.50–2.20 W/(m²·K)
- 武汉（居住建筑，≥4层）：屋面 ≤0.30 且 D≥3.0、南北朝向外墙 Kmi≤1.0、东西向 ≤0.75 W/(m²·K)
  （2025-11 超低能耗指南收紧为 0.80 / 0.60）

### B. 建筑实测运行数据 —— **只有文献级零散点位，无平台级数据**

**乌鲁木齐（实测最丰富）**
- 居室晚间均温 21.5 ℃、卧室 22.0 ℃（2004-01，30 min 间隔，连续 5 天）
- 集中供暖室温稳定 ≥20 ℃；燃气壁挂炉 ≈23 ℃；煤炉 15–27 ℃
- 采暖室外计算温度 −19.7 ℃、极端 −32.8 ℃、采暖天数 180 d、HDD18 = 4329 ℃·d
- 既有住宅实测 K：外墙 ≈1.02、平屋面 ≈0.97–1.0 W/(m²·K)；改造后 0.29–0.42 / 0.27–0.34

**宁夏（银川/中卫，非固原）**
- 370 砖墙 K=1.05、土坯墙 K=1.42 W/(m²·K)；新建民居东西北墙 K₀=0.38、南墙 1.05
- 中卫农宅 370 mm 外墙实测 **1.47–2.0** W/(m²·K)、室外均温 −2.74 ℃、RH 23–54 %
- 银川冬季均温 −13.1 ℃、采暖室外计算 −13.0 ℃、采暖期 153 d

**武汉**
- 住宅总耗电 9.0–36.9 kWh/(m²·a)、**空调耗电 1.0–9.8 kWh/(m²·a)**（1998–99，约 200 户）
- 城镇空调器拥有率 62.5 % vs 农村 3.1 %；城镇冬季集中供暖仅 14.2 %
- 能耗限额（2015 版）：住宅综合能耗基准 9.02 / 引导 7.46 kgce/(m²·a)

### C. 单位面积热容 / 热惰性 / 换气次数 —— **拿到，但都不是三城本地值**

- **单位面积热容**：ISO 13786 附录 A 默认值 极轻 80 / 轻 110 / 中 165 / 重 260 / 极重 370 kJ/(m²·K)。
  ⚠️ 这是**国际标准默认值**，中国规范未直接给出该量；**三城本地值 `not_found`**。
- **热惰性指标 D**：GB 50176 体系 D=R·S；Ⅰ类 D>6.0、Ⅱ类 4.1–6.0、Ⅲ类 1.6–4.0、Ⅳ类 ≤1.5
- **换气次数**：GB 50736-2012 居住建筑最小换气次数按人均面积 0.70 / 0.60 / 0.50 / 0.45 次/h；
  厨房卫生间 ≥3 次/h；GB/T 18883 人均新风 30 m³/(h·人)
- **占用日程**：国标附件有"人均占地面积—人员在室率—设备/照明功率密度"参数表（未下载）

## 三、方法与工具说明

- **`nature-academic-search` MCP 的 `search_papers` 全程报错**：`asyncio.run() cannot be called from a running event loop`（该 MCP 服务端缺陷）。
  `get_paper_by_id`（DOI 验证）与 `lookup_mesh` 可用。
  **替代路径**：直接用 OpenAlex REST API（`api.openalex.org/works?search=...`）与 WebSearch 交叉，
  原始 JSON 存于 `sources/lit/`，均在 `receipts.json` 留痕。
- 网络统一走代理 `127.0.0.1:7897`；固原市政府 PDF 的 `http://` 链接返回 **405**，改 `https://` 后成功（14.4 MB / 188 页）。
- 数值抽取一律标注**取值性质**（实测 / 标准限值 / 文献值 / 设计参数 / 政策参数），
  **标准限值绝不冒充实测值**；境外数据（BDG2 等）只作对标记录，不进入三城取值。

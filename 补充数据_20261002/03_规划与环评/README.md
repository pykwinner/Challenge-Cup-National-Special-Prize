## 三、三城/省级 关键数字速查

### 武汉（本次从 0 到有）
来源：武汉市发改委 2020-05-25 政协第 20200504 号提案答复
- 全市民用及商业供热建筑面积约 **1800 万 m²**，受益人口约 **50 万人**
- 全市供热总需求约 **4100 t/h**，全市集中供热能力 **2289 t/h**（能力不足）
- 5 处热电联产热源点：阳逻电厂(汉口)、晨鸣热电厂(汉阳)、青山热电厂/武昌燃机热电厂/东湖燃机热电厂(武昌)
- 外热入汉：汉川电厂最大供热能力 **340 t/h**、鄂州电厂 **240 t/h**
- 地源热泵供热制冷面积约 **200 多万 m²**；天然气中央空调 20 多家约 150 万 m²
- 产能利用率参考：武昌燃机 44.5%、青山热电厂 16.3%
- 汉口滨江国际商务区江水源可再生能源站：**设计供能规模 211 万 m²**，总投资 59944 万元，2020-01 启动（设计值）
- 青山区余热供暖项目：**总规划供暖面积 3040 万 m²**、惠及 80 余万人（规划值）
- 长江日报/荆楚网：中国燃气 3 年在武汉投资 220 亿元新增 1 亿 m² 供暖面积（商业承诺）

> **口径提醒**：2289 t/h 是「供热能力」，4100 t/h 是「供热总需求」，二者均非供热量（GJ）；武汉本地**没有**逐时或年供热量的公开数据。

## 四、硬规矩（引用时务必遵守）

1. **不编数值**。本目录所有数字均带「数据性质」标签，取自 `tables/source_capacity_extracted.csv` 或 `来源与适用范围_补充.csv` 的「限制」列。
2. **规划目标 ≠ 现状**。湖北省级的地热能 5000 万 m²、生物质 160 万千瓦、煤耗 297 gce/kWh 是**2025 年规划目标**，不可当作现状值写进论文。
3. **环评设计值 ≠ 实测运行值**。乌鲁木齐 6 项、固原 2 项均为**批复/公示的设计值**；固原彭阳的「已投运/停运」是 2021-05 时点状态。
4. **同一项目多口径必须先声明口径**。泾源县项目 2021-01 与 2021-07 两个公示，t/h 与 MW、管网长度、投资额均不同：
   - 2021-01：总供热量 3×80 t/h，近期 2×80 t/h，一级管网 2522×2 米，满足 169.23 万 m²，18503 万元
   - 2021-07：2×58 MW，一级管网 4072×2 米 + 二级管网 900×2 米，23798.52 万元
5. **华电乌鲁木齐热电厂装机两口径矛盾**（正文 2×300 MW vs 标题 2×330 MW），引用前必须回原始核准文件（发改能源〔2008〕347号）核对。

## 六、给下一步的建议

1. **武汉热源侧数据最缺的是「供热量」**：现有官方口径全是 t/h（能力）与万 m²（面积），没有任何 GJ 或万 GJ。建议用 4100 t/h 需求 / 2289 t/h 能力这两个锚点做量级校核，并在论文中写明是能力口径而非供热量。
2. **武汉本地热源清单已可用**：5 处热电联产 + 3 座天然气分布式 + 1 个集中供暖中心 + 汉川/鄂州外热入汉，足以替换「代理假设值」。
3. **大机组的实测级数据**（华电乌鲁木齐、红雁池、米东）建议走**排污许可执行报告 / 自行监测方案**（全国排污许可证管理信息平台 permit.mee.gov.cn）或企业官网，环评路径已证明不可行。
4. 固原若需要生物质专项，本批未覆盖到生物质项目（本次命中的是燃煤集中热源），可另起一轮针对「生物质锅炉/生物质热电联产」的检索。

# 11_经济边界｜三城市供热项目「经济边界」补充检索（2026-10-02）

**定位**：本目录是 `三城市论文补充数据包_20261002` 的第 11 个子目录，只做一件事——
在公开源**尽最大努力**检索"经济边界"证据（计费身份 / 燃料与余热合同 / 改造前基准 / 补贴与政策资金），
并把每条数据的**来源、抓取时间、原文件、限制**登记清楚。

**不覆盖、不替代**原包与其余子目录。已有的分月电价（`01_电价`）、供热到户价（`08_供热价格`）、
生物质市场价（`04_设备价格与生物质`）**本次一律不重做**。

**红线**：所有数值均可回到 `sources/` 里的原始件；**没有找到的一律标 `not_found` / `located_not_packaged`，
未做任何编造、换算或推断**。

## 硬规矩执行说明

1. **不编数值**：`tables/economic_boundary_extracted.csv` 的每一行都可在 `sources/` 原件中逐字指出。
2. **口径分列**：`数据性质` 列区分了 **招标预算 / 中标(成交)价 / 中标候选人报价 / 市场价 / 合同价 /
   成本监审值 / 政府定价 / 债券披露（预测） / 环评设计值 / 规划 / 报道**。
   - 招标预算 ≠ 成交价（西城热力三人报价标为"中标候选人报价"）
   - 运输单价 ≠ 煤价（彭阳运费与煤价分行）
   - 成本监审值 ≠ 实际结算价（监审行只写监审结论）
   - 拟申请中央财政资金 ≠ 已到位（固原 90000 万为"拟申请"，乌市 21 亿与 16.8 亿两口径并列）
   - 环评设计值 ≠ 实测运行值（年耗气/耗电均为环评设计口径）
3. **找不到就留白**：本包共 `not_found` / `located_not_packaged` 条目见 `来源与适用范围_补充.csv`。

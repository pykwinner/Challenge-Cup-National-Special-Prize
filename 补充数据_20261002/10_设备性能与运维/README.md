# 10_设备性能与运维（供热设备技术参数与运维费用·公开源检索）

检索与归档日期：2026-10-02（Asia/Shanghai）。本目录为新建，未改动本项目其他任何文件。

## 目的

用户此前判断"供热设备的技术参数与运维费用公开源找不到"。本轮按 A–E 五个方向做了一轮真检索，
结论：**大部分能拿到，且质量不低**——尤其是低温热泵国标限值、招标技术参数表、蓄热损失要求、
生物质/电锅炉性能门槛、三地成本监审与三个运维中标总价。缺口集中在"能效标识网备案级数据"
与少数已下架附件（详见第 6 节）。

## 分方向结论（A–E）

### A. 空气源热泵低温工况性能（最关键）—— 拿到，两类口径

1. **国标限值（GB 19577-2024 表3，全文已归档）**：>35kW 机组 COPdh 地板 2.10 / 风盘 1.80 / 散热器 1.50，
   COPh 2.50 / 2.30 / 1.80，HSPF(APF) 分 1–3 级（如地板 3.40/3.20/3.00）；≤35kW 户用 COPdh 2.00/1.80/1.50。
   低温试验工况（-20℃等）的完整条件未随附，工况口径由 XJJ090-2018 与河北招标文件交叉印证：
   名义 -12℃干球/-14℃湿球、出水 41℃。
2. **招标技术参数表（含 -12/-20/-25℃ 分档 COP，6 份）**：
   - 河北邢台（2025）：7/6℃ ≥348kW/COP≥3.41；-12/-13.5℃ ≥200kW/COP≥2.43；**-20℃ ≥173kW/COP≥2.10**；-25℃ ≥144kW/COP≥1.8
   - 甘肃卫生职业学院（2024）：额定 ≥170kW/COP≥3.3；名义 ≥115kW/COP≥2.6；低温制热量 ≥96kW；IPLV(H)≥2.9
   - 甘肃办公楼项目：**-12℃/出水41℃ ≥115kW/COP≥2.6；-20℃/出水41℃ ≥93kW/COP≥2.2**；IPLV(H)≥3.05
   - 河南鹤壁（2024）：出水35℃名义 ≥101–102kW、COPh≥2.7–2.8、HSPF≥3.0
   - 河南新乡（2023）：150kW 档、IPLV(C)≥3.5
   - 新疆 XJJ090-2018（地方规程）：设计工况 COP 冷热水≥2.0、HSPF≥2.0、融霜修正 K3=0.9/0.8
   - 制热量衰减可直接按同文件多工况要求值算比值（如河北 -12→-20℃ 为 200→173 kW，约 −13.5%）。
3. **没拿到**：中国能效标识网备案查询（站点不可达）、CQC 判定表原件（链接失效）、
   佛山检测项目表（已下架）、国家压缩机制冷设备质检中心的公开检测报告原件。

### B. 蓄热/储热损失与效率 —— 拿到

- 24h 温降要求：**甘肃 ≤3℃**（保温≥6cm，原件已下架，检索摘要口径）；**贵州 ≤5℃**（50mm 聚氨酯）；
  **广西 ≤5℃**（50mm 聚氨酯，含水箱报价）。
- 保温构造：内蒙古包头 ≥50mm 聚氨酯、密度≥35kg/m³（★条款）。
- 效率/损失（新疆 XJJ090/XJJ092-2018，扫描件已 OCR）：
  蓄热装置**热量利用率≥90%**；**24h 散热量 < 需热量 5%**；隔热层外表面 ≤环境+25℃；
  电极锅炉 24h 保温散热损失**<1%**；蓄热温度常压 85–90℃ / 高温 120–140℃；保温外壳表面 20–25℃。
- 上海标准（扫描件）为测试方法口径（20:00–6:00、≥50℃、温差≥20℃、U_SL 公式）。

### C. 生物质锅炉 / 电锅炉 / 板式换热器 —— 拿到

- 生物质锅炉：平度 2×35MW（**热效率≥90%、调峰 30–130%、连续运行≥3600h/年**、燃料 3500kcal/kg）；
  湛江 90t/h（**≥87%、最低稳燃 30%、50–100% 负荷汽温±5℃、110% 超负荷 2h**）；
  黑龙江 DB23 指南（负荷 **70–100%**，热效率 88/83 与 91/86 目标/限定）；
  国标评价准则（**年可用小时≥7200h**、30–110% 负荷可调为满分档）。
- 电锅炉：XJJ092-2018 **电极>98%、电阻>98%、半导体>98%、电磁>97%、固体蓄热综合>95%**，
  附录 C 电极式综合热效率≥99.9%（24h 散热<1%）；XJJ090 设计取值 0.97；
  大唐蔚县实例（2026）**电极热水锅炉 50MW 热效率≥99.5%、出水 110℃、0–100% 负荷**。
- 板式换热器/换热机组：扬州（3.619MW、一次 110/80℃、二次 75/60℃、承压 1.6MPa）；
  黑龙江（板换压降≤0.03/0.04MPa、机组≤0.06/0.06MPa）；潍坊（面积富裕≥30%）。

### D. 运维费用 —— 拿到（这是本轮最完整的一块）

- **成本监审（官方口径，4 地）**：青岛 3 个供热年度分项成本（2023-24 单位成本 61.84 元/m²，
  含能源 39.66/薪酬 7.88/折旧 3.06/修理 1.20）；和硕县 3 年核定数（单位成本 20.58/21.27/20.57 元/m²、
  折旧与运维分项、煤款与工资核定值）；伊宁县 4 点位（13.73–32.10，加权 18.50 元/m²，含 3% 利润率）；
  特克斯县（上报 22.38→核定 20.77 元/m²，热损按 5% 核定）。
- **省级监审口径（山东 2024）**：标煤耗 ≤20 kg/m²·采暖期（面积计费）、热损 ≤5%、修理费 ≤原值 2%、残值率 5%。
- **运维中标总价（3 个）**：扎兰屯监狱 1,199,100 与 1,350,800 元/年；免渡河林业局 3,790,000 元/年
  （18.1 万 m²、热源≥8MW，含燃料/人工/运维/电费）。均为年总价，未折算单价。

### E. 管网与换热站 —— 拿到（运行参数，未重复 04 节设备价）

- 流量指标：一次网 ≥8 t/h·万m²、二次网散热器 ≥25、地热 ≥40（热指标≤45W/m²）；管道比摩阻 ≤100Pa/m。
- 泵：扬州循环泵 330m³/h·44m·55kW（一用一备变频）、补水泵 7m³/h·48m·2.2kW；
  甘肃办公楼一次泵 ≥200m³/h·17m·15kW、二次泵 ≥80m³/h·47m·18kW。
- 水温参数：潍坊板换一次出水 地暖45/暖气片55℃、二次 40→50 / 50→65℃；
  扬州二次设计 75/60℃、校核一次 95/65℃。
- 水质：pH7–8.5、溶解氧≤0.1mg/L、悬浮物≤5mg/L、氯离子≤25ppm。

## 使用注意

1. `sources/extracted_txt/` 中的 .txt 为 pymupdf 批量提取的正文（便于检索原文），扫描件（新疆两份、
   上海、内蒙古政采部分页）在 txt 中为空或有 OCR 摘录文件对应。
2. 招标文件中的性能值为**采购门槛**（★条款），不是实测；引用时建议保留"依据 GB/T 25127.1 检测报告"的语境。
3. 成本监审数据的"平方米"口径各地不同（青岛为使用面积，和硕为建筑面积），横向比较前先对齐口径。
4. 所有文件 sha256 / 抓取时间 / HTTP 状态见 `receipts.json`。

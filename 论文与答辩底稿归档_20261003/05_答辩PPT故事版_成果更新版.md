# 答辩PPT故事版：成果更新版

2026-10-03。主讲15页，面向决赛评委。本版在04故事版上吸收最新的舒适带与H/C敏感性、作息间歇供热、源网荷储联合选型，以及异质楼宇三层耦合实验。已核对相关原始配置、决策表、求解与审计记录，并查看新增图件。03技术大纲与04故事版均保留。

**本轮叙事变化：用三个会影响投资和运行的决定承接技术成果——按作息怎样选设备，储热值不值得配，接入受限后怎样协调各栋楼。** 原来的大幅节费减碳结果保留为技术路线比较，算法贡献通过具体决策与受控对照说明。

团队经历口径已由用户补充：目前主要完成线上资料研究、老师指导与建模实验；线下走访尚未开展，拟于近期推进。本版以已有研究成果讲述完成过程，另备走访计划与完成后可替换的讲稿。

**全场记忆句：让供热方案，在建设前先过一个冬天。**

**项目定位：面向规划院与热力公司的供热方案预演工具。** 当前成果为模型与算法工程研究原型；从真实楼宇验证走向片区规划工具，是下一阶段目标。

## 一、故事由谁来讲，评委为什么要听

故事围绕一个供热项目的决策展开：住户希望回家就暖，建设方关心初始投资，运营方关心后续费用，规划者还要考虑电力接入与碳约束。这些要求最终必须落在同一个方案里。中段不断回到这四方：作息改变了设备选择，储热的收益需要与投入比较，共享容量又改变了各栋楼的运行。

开场采用“设想武汉一个准备建设的小区”的明确假设情境，不把它写成已经签约或完成调研的真实项目。随后进入武汉单栋条件投资实验，并用另外两套已跑通的联合配置，展示储热与管径选择、上层接入约束对楼宇运行的影响。

整场的推进顺序是：

**一张难以决定的建设方案 → 一支把疑问变成对照的团队 → 一个完整冬天的运行记录 → 三个算过之后才看清的选择 → 一条进入真实项目的路径。**

评委听完应记住三件事：

1. 这项工作瞄准供热投资之前的方案选择，关系到后续多年运行。
2. 团队已在明确条件下把整季运行与费用碳排算出来，并识别了几个会改变决策的机制。
3. 如果获得真实项目数据和联合试点，下一步要交付什么、怎样检验价值，已经想清楚。

## 三、逐页画面与口播

### 第1页：暖城向新·热力不息

**副标题：让供热方案，在建设前先过一个冬天。**

正式题目“面向供热格局变革的城镇供热源荷匹配与规划寻优”放在次一级位置。保留赛题编号、学校、团队和答辩人。

**画面：** 一侧是项目规划图纸，另一侧是冬季建筑的温暖窗光，视觉对应“今天的设计”和“未来的生活”。若使用情境配图，标注示意，不能让它看起来像项目现场实拍。

**口播：**

> 各位评委老师好。我们希望做一件事：在供热设备采购、管道铺设之前，让一个方案先在计算机里经历完整的冬天。把够不够暖、需要多少投入、运行要花多少钱，提前放到同一张桌上讨论。

### 第2页：一张供热方案，要回答四方的期待

**屏幕只留四句话：**

- 住户：回家时，房间能不能已经暖起来？
- 建设方：现在该投入多少，设备该配多大？
- 运营方：进入冬天以后，运行费用能不能承受？
- 规划者：电力接入、空间条件和碳要求能不能满足？

**画面：** 以同一张小区规划图为中心，四种角色围绕它提出要求，避免四块无关联的口号。

**口播：**

> 请大家设想，武汉有一个准备建设的新小区。居民希望回家就暖，建设方希望控制投资，运营方要考虑每个冬天的电费，规划者还要看接入能力和低碳要求。四方的期待，最后都要落在同一张设计图上。等图纸变成设备和管道，再调整就要付出代价。我们想把更多比较，放到建设之前完成。

**衔接：** “而今天，这张设计图上的选择正在变得更复杂。”

### 第3页：热源的选择更多了，规划要算的账也更多了

**屏幕：** 三条转型路径沿一张地图展开：北方大网寻找低碳替代；分散供暖寻找清洁路径；南方新建供热寻找适合自身需求的方案。

**核心句：设备选什么、什么时候运行、热能送多远，需要一起考虑。**

**口播：**

> 三类地区面对的起点不同。北方大网要考虑既有资产怎样利用，分散供暖要考虑清洁替代的投入，南方新建供热则要从服务需求出发选择路径。只比较设备额定效率和全年总热量，还看不到某个寒冷时段够不够用，也看不到多栋楼同时用热时会发生什么。我们把这些选择放到逐时运行条件下检验。

**页脚：** 武汉为主案例气候；乌鲁木齐、固原为同原型气候对照。三城对照不代表三地已有真实工程落地。

**素材入口：** 原大纲第2、4页及三城空间参考图。

### 第4页：把资料变成输入，把疑问变成实验

**屏幕：** 以四份真实工作成果串起过程：公开原件与来源表 → 设备工况表 → 对照实验 → 复算报告。

**只突出两个工作量：** 三城资料研究；两型号165个设备工况点。其余工作量分配到对应成果页。

**口播：**

> 推进这个课题时，我们先面对的是分散在气象、规划、电价和设备资料里的信息。团队把三座城市的公开资料分类整理，再逐项判断哪些条件能用于当前实验。设备端，我们纳入两种型号的165个工况点，分别处理供热能力和输入功率。进入建模后，每一个关键判断都尽量安排对照：换一种气候、收紧一条边界、改变一个参数，看看结论是否还成立。后面的结果，就是沿着这条研究链逐步形成的。

### 第7页：只在需要时供暖，设备应该怎样选？

**案例A，主图：** [intermittent_service.png](../outputs/figures/intermittent_service.png) 的室温时序与运行指标。正式制作把图题改为“按作息供热：运行费下降，低碳端点的设备选择发生变化”，避免把两台设备说成满足服务的必要条件。

**情境：** 声明在06—09、17—23时段满足20—27℃，其余时段允许退温至12℃。这是一种待现场核定的服务设想。

**屏幕把两种比较清楚分开：**

| 比较 | 连续服务 | 声明作息服务 |
|---|---:|---:|
| 折中候选：热泵台数 | 1台 | 1台 |
| 折中候选：窗口电费 | 611.18元 | 494.95元，约−19.0% |
| 折中候选：窗口碳排 | 355.30 kg | 277.10 kg，约−22.0% |
| 低碳端点：热泵台数 | 1台 | 2台 |
| 低碳端点：设备投资 | 19,300元 | 37,100元 |

**口播：**

> 回到居民的需求：不在家的时候，能不能允许房间降一点温，回家时再满足舒适要求？我们把这个问题改成逐时服务条件。结果是，一台热泵的折中候选仍能满足设定，窗口电费下降约19%。但继续追求最低碳排时，模型在候选中选了两台设备，投资也随之增加。服务方式、低碳目标和设备投入，会共同改变答案。提前算一次，就能把这种取舍带进方案讨论。

**一句结论：按需供热值得做，但设备配置要随服务目标一起比较。**

**可见图注：** 单栋原型、设计代理COP、声明作息；服务时段舒适检查通过。空置时段允许提前预热，未要求设备完全停机。19%来自服务条件改变后的比较，不能作为同等全天服务下的纯算法节费率。

**备份：** 两个对照的服务要求、审计和连续对照复现记录。一台折中方案已经可行，因此讲“低碳端点选两台”，不讲“间歇必须两台”。

### 第8页：储热罐值不值得配，让方案自己回答

**案例B：** 既有热源、候选干线、建筑室温、储热容量放进同一次2880小时求解，使用分时电价。

**画面：** 已有热源 → 管径选择 → 建筑服务，旁接储热候选。右侧直接展示两个条件下的选择。

| 决策 | 登记结果 |
|---|---|
| 干线dn50或dn80 | 选择dn50 |
| 储热造价情景260元/kWh | 配置0 kWh |
| 仅将储热造价改为5元/kWh | 配置约13.63 kWh |

**口播：**

> 接着，我们把管网和储热放进同一次选择。一个有意思的结果是：在登记的造价条件下，模型选择了较小的管径，储热容量选为零。为确认储热候选确实参与了决策，我们降低它的造价重新计算，结果选出了约13.63千瓦时。这个对照说明，设备进入了候选，也需要通过投入与收益的比较。规划工具应当能解释为什么配置，也能解释为什么暂时不配。

**一句结论：让每一项配置都有进入方案的理由。**

**可见图注：** 单栋、两节点单干线、既有理想电锅炉；管网与储热参数为声明情景，财务权重非工程回报设定。260档求解器报告gap为0；5档相对gap约0.004%，均通过登记数值与舒适校核。

**制图依据：** [joint_selection.png](../outputs/figures/joint_selection.png) 作为参考，正式页按上表只保留“同一联合配置260与5两档”。原图中的精确阈值、投资折算说明和不加范围的“证明最优”需按本稿末尾核对说明替换。

**机理备份：** 建筑热容提供一定调节空间，C×7℃约3.75 kWh是名义热库存；现有对照没有单独证明它是储热选零的唯一或主要原因。主讲以造价改变后选择切换这一直接证据为准。

### 第9页：接入容量收紧，各栋楼的运行一起改变

**案例C，主图：** [multiscale_three_level.png](../outputs/figures/multiscale_three_level.png)。讲清“系统级接入—两条干线—两栋不同热容建筑”的传递关系。

**本页主结果只用异质楼固定接入上限扫描：** A楼C1、B楼C4，其他登记条件相同。

| 共享接入条件 | 120日运行费 | 总取电 |
|---|---:|---:|
| 宽松接入 | 4,298.54元 | 6,988.61 kWh |
| 6.4796 kW | 4,405.67元 | 6,805.3 kWh |
| 5.2 kW | 4,462.40元 | 6,710.27 kWh |

**大字：收紧至5.2 kW，运行费+3.81%，用电与固定因子碳排−3.98%。** 各案两栋楼的仿真舒适校验通过。

**口播：**

## 四、怎样把“潜力”讲得有分量

### 1. 把技术结果接到一个具体决定上

| 技术表述 | 答辩时接上的意义 |
|---|---|
| 建筑逐时热状态计算 | 设备方案能否在给定条件下持续满足服务要求 |
| 费用与碳端点、碳帽约束 | 预算和低碳目标不同，可以比较不同候选 |
| 共享容量受控实验 | 每栋楼的运行安排需要考虑共同资源 |
| 温压校核反馈 | 部分便宜方案需要付出额外代价才能满足输配边界 |
| 作息间歇与设备选择 | 在家够暖、离家退温的要求，会改变运行费用与低碳端点配置 |
| 联合选型与储热造价对照 | 储热作为候选是否进入方案，可以随条件切换 |
| 异质楼宇接入容量扫描 | 系统边界会改变各栋楼的运行及费用、能耗取舍 |
| 代表日权重校正 | 扩大比较范围时，要先控制时序压缩带来的失真 |
| 版本化输入与独立复算 | 规划者能够追问一个结果来自哪些条件 |

### 2. 用应用路线替代泛泛市场口号

潜力可以落在三种持续发生的工作上：新建项目比较技术路线，存量项目评估改造选择，条件变化后重新审视原方案。工具若能降低整理数据、反复计算和核对结论的成本，就有重复使用的理由。

目前尚未测得真实用户节省多少工时、减少多少投资或愿意支付多少费用。把这些写成试点验收指标：同等方案深度下的分析工时、可行候选覆盖、预测与实测偏差、独立复算一致性，以及工程师是否据此调整选择。

### 3. 让主讲形成推进感

主讲优先呈现“问题—证据—决策意义”。必要实验条件留在对应页面的可读图注里，详细数学推导、审计过程和来源索引进入备份。全场重点停在第6—9页与第14页；第11页负责回答“收益归因”，不把它讲成独立的成绩展示。

最后一页回到用户与应用。当前不足在相应结果页准确交代，并在应用路线中说明验证任务；结尾不逐项朗读未完成事项。

> 近期的走访，我们准备带着三个问题去：用户真正需要怎样的服务，设备运行有哪些现场限制，项目在投资时最看重什么。我们的目标是把回答转化成下一轮模型的输入、约束和评价条件，并请工程人员判断输出是否能帮助他们比较方案。

本页如加入正式15页，可替换第14页路线图的上半部分，保留下半部分“真实楼宇—片区联合—多项目复用”。尚未走访时不放暗示已经到访的现场照片。

### 4. 走访时记录什么，回来才能写成有价值的故事

| 拟交流对象 | 核心问题 | 留下的工作材料 | 可能进入模型的位置 |
|---|---|---|---|
| 住户或建筑管理人员 | 哪些时段需要供热？多久升温可以接受？现有服务有什么具体问题？ | 匿名访谈要点、服务时间表、经允许记录的现场条件 | 占用与作息、舒适要求、间歇恢复时间 |
| 设备或运行人员 | 型号、出水温度、低温能力和备用方式是什么？哪些限制影响运行？ | 型号与工况记录、运行问题清单、可提供资料目录 | 设备能力、运行边界、备用与控制方式 |
| 规划或热力工程人员 | 比选时哪些成本必须计入？哪些条件会否决一个方案？ | 成本构成、决策条件、对输出样例的意见 | 生命周期费用、资源接入、候选筛选与报告结构 |

不预设“访谈证明我们正确”的结果。现场发现与原模型不同，同样可以成为有力度的过程故事：原先采用什么假设，现场信息揭示什么差别，团队据此修改什么，再验证结论是否变化。

### 5. 完成走访后再使用的讲稿模板

以下为素材组织模板，方括号内容尚无事实，不进入正式答辩稿：

> 在[实际日期]，我们与[真实对象及地点]进行了交流。对方提到[有记录的具体问题或原话摘要]，这让我们重新检查模型里的[具体假设]。随后，团队把[实际取得的资料或边界]纳入[具体修改]，并比较了[修改前后真实结果]。这次交流推动我们完善了[实际发生的改进]。

如走访后尚未完成模型修改，结尾改为：“我们已把这一问题列入下一轮验证，接下来将检查它对方案选择的影响。”

### 6. 团队展示怎样更有画面

优先选真实工作材料的局部：一页带标注的设备样本，一张反映方案比较的表，一幅前后结果不同的曲线，一份复算报告。每张画面配一个动作：“核对”“对照”“修正”“复算”。教师指导和团队讨论照片按实际日期与内容标注。

走访完成后，可用“现场发现—团队讨论—模型修改—结果对比”四幅材料替换其中一组。照片承担引入作用，真正体现团队贡献的是它如何改变了研究。

### 本轮读取原始记录后统一的技术口径

1. **源网荷储联合算例已经有2880小时分时电价结果。** 已有热源固定，管径和储热为候选，建筑有逐时RC状态；不再沿用“源网荷储从未联合跑过”的旧表述。
2. **三层耦合有新增原型证据。** 两栋异质楼的5档接入扫描通过登记求解与舒适校核；另有同质楼扩容候选案。两者分别展示。案例C的独立储热列表为空，与案例B不合并为同一完整工程。
3. **gap为0是求解器在登记模型与容差内的最优终止报告。** 联合造价5元/kWh档gap约0.004%；不要把全部造价扫描都写成gap为0。
4. **联合/多尺度配置的财务系数不是实际项目条件。** `discount_rate=1.0`、`asset_lifetime_years=1`对应资本回收系数2。联合3万元管径对应模型资本项6万元；两条共3.6万元管线对应模型资本项7.2万元。主讲比较运行费和选择结果，不把总目标解释为一次投资或真实年账。
5. **2265.428715这一相同下界来自简化参考问题。** 它不是联合管网/储热案例的最优值，且参考运行的可行目标与下界仍有gap。可留作数值排查线索，主讲不称“两套联合实现逐位互证”。
6. **储热选零的直接证据是条件变化后的配置切换。** 名义建筑热库存3.75 kWh可用于机理讨论；未通过隔离对照证明它就是储热选零的原因。也不把未完全最优终止的扫描点转换为精确价格阈值。
7. **低于5.184 kW的边界受本配置的firm约束影响。** 不直接宣称为所有建筑的物理最低需量；只有配置或口述失败、没有完整失败记录的点，不列成已核验运行。主讲采用已完成的5.2—6.4796 kW扫描。
8. **团队迭代可以讲排查与改进，不把同质/异质泛化成定理。** 早期配置排查涉及firm判定和建筑热容等多项因素，不说“同质建筑必然不能移峰”。

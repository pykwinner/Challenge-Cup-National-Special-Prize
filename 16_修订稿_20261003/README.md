## 编译

```bash
# 主报告
cd 16_修订稿_20261003
xelatex -interaction=nonstopmode -output-directory=build main.tex   # 两遍
# 数据表
cd 数据表
xelatex -interaction=nonstopmode -output-directory=build 仿真结果数据表.tex   # 两遍
```

需 TeX Live 2023+ 或 MiKTeX，引擎 XeLaTeX；中文字体随包在 `build-fonts/`。编译后应检查：`Overfull` 不超过 2pt、无 `LaTeX Error`、无 `undefined` 引用、PDF 中无残留 `??`。

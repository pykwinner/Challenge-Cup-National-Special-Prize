# PPT和实验数据补充要求

PPT按以下顺序组织：选题原因；九名成员的姓名、具体分工和交付成果；主要内容概览；研发时间线；正式陈述核心内容与实验结果；与企业联合精进和补充的过程；企业认可或鉴定结果；不足与展望。

研发时间线采用实际版本记录。7月简版、8月精版、10月版是用户给出的展示顺序示例，只有已完成且有依据的版本才能写为完成；尚未完成的明确标注计划。不得为了叙事编造数月工作、人员贡献、企业合作或鉴定。

实验数据来源必须真实可查，不得伪造。每项关键数据与图表标注来源机构/文件/链接、年份、单位、适用场景和可定位页表。原始实测、规范限值、统计、报道数值、模型假设及仿真输出明确区分；仿真结果不得冒充现场实测。缺失字段列出缺口，确需情景值时注明假设及依据。

企业合作与鉴定使用真实书面材料、可核对反馈及实际修改前后记录。没有取得认可或鉴定的，不写成已获得认可。目录中的通用案例报道不等同企业对本参赛项目的背书。

本文件只记录补充要求，本轮未编辑PPT，也未补造项目事实。

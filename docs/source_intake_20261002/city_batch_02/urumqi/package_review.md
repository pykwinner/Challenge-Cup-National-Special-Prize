# 乌鲁木齐新数据包只读核对（2026-10-02）

数据包补充了可追溯的公开材料和采集接口，仍未补齐本城建筑、设备、资源、管网、报价及全期电价的项目证据。乌鲁木齐603条配置记录（季节295、年度308）全部标为 `inherited_model_setting_or_assumption_NOT_project_verified`；本次新增独立项目观测为0。

本轮读取包内README、核验结论、乌鲁木齐字段出处/配置登记/来源线索、电价参考、13张采集模板及本城市政策原文和表格。没有运行包内代码、重建、优化或测试。NASA全量数值与全包完整性核验由主对话负责。完整逐字段与模板核对见[package_review.json](package_review.json)。

5张时序模板仅表头，没有任何观测记录。其余8张模板的乌鲁木齐行只有节点/资产/年月等标识和缺失状态，实质参数及证据格全部为空；空白不能按0读取。

包内电价参考以工商业单一制1—10kV为假定类别，用户实际分类、分表计量、购电方式与基本电费仍未核。总note声称逐时价格均有官方依据，但README、文件名和逐字段登记明确全期未核，后者应作为使用边界。2024年11月价目及其±2%表述，本轮不认证其原始价目或全季适用性；所列来源 `jmser.gov.cn` 是异地转载线索，不能替代新疆供电企业每月原始价目和项目账单。2024年10月才生效的通知不能追溯认证2020—2023电价。

包内“乌鲁木齐供热规划草案”源页是[2025-06-06征求意见公示](https://www.wlmq.gov.cn/wlmqs/c119242/202506/282e876f9e074a4f837ea68ae7b30f59.shtml)，`audit/live_source_recheck/urumqi_plan.html`也是同一草案。页面同时有2026年的HTML元数据时间，不改变正文草案身份。城市“现状”40/46/65 W/m²或2278MW汇总即使写在政府规划内，也不能映射成模型某栋建筑或650kW余热设备的实测值。本轮已核[2026-01-07公布规划正文](https://www.wlmq.gov.cn/wlmqs/c128188/202601/a5bed3c0c5e24011a254b71bf5d495f8.shtml)，使用时要保留版本；两份规划版本不构成两个独立测量证据。

包内[新发改规〔2024〕6号](https://xjdrc.xinjiang.gov.cn/xjfgw/c108396/202408/296e2c8eb46b462882330c0acab18242.shtml)为同一自治区通知的另一官方栏目版本，与本轮已核规范性文件版本重复。成文2024-08-20、生效2024-10-01、有效3年；居民0.22元/kWh有接入和分表条件，非居民集中供热谷段50%只作用于输配电价。归档政策原件是有效参考，但没有新增项目资格认定或账单。

包内67条来源线索未逐条重新核实，其中乌鲁木齐17条只是历史线索；有正式2026规划链接不等于该包已经归档和适配了正式正文。原包以另一机器的`north_heat_challenge_heating_season_code_20260825`及历史15.pdf为目标。README中“用户指定最终15.pdf”和“当前虚拟热惯性未实现2R2C”均是资料自身的历史说明，不是当前稿件基准指令，也不据此判断当前V10 `building_thermal.py`。本轮不改论文或正式模型。

仍需实际建筑台账及热计量/室温/围护资料、余热源温度流量功率与停产保供记录、批准/竣工管网GIS和水力参数、设备性能曲线及工程量报价、储热与地层资料、供电类别认定和逐月合同账单。

## 1. 升级结论

V11 在保持 V10 三场景数学模型和既有求解结论不变的基础上，增加了“国家战略参考画像—地方/项目目标—模型硬约束—求解结果—对齐报告”的完整链条。

本次升级解决了三个问题：

1. 过去的“清洁热”同时包含余热和可再生热，无法直接对应国家文件中的“余热利用”和“非化石能源供热”两种不同口径；
2. 国家宏观指标、行业指标和项目指标容易被直接套用，造成分母不一致和伪精确；
3. 政策内容主要停留在报告文字中，缺少可校验的来源、适用期、模型字段和自动化对齐输出。

V11 新增非化石热独立账本、直接化石排放账本、相对基线减排约束、政策画像校验和政策对齐 CLI。国家宏观目标默认不参与项目合规判定，只有地方任务已分解、基线经审计且分母一致时，才允许显式转为模型硬约束。

## 2. 国家战略依据

### 2.1 “十五五”规划纲要

[《中华人民共和国国民经济和社会发展第十五个五年规划纲要》](https://www.gov.cn/yaowen/liebiao/202603/content_7062633.htm)明确了以下与供热转型直接相关的方向：

- 到2030年，单位国内生产总值二氧化碳排放降低17%；
- 单位GDP能耗下降约10%；
- 构建清洁低碳、安全高效的新型能源体系，推进非化石能源有序替代；
- 推进煤电改造升级和散煤替代，完善城乡配电网并发展新型储能；
- 加强既有建筑和市政设施节能降碳改造；
- 推动热力系统绿色低碳转型，因地制宜利用余热和非化石能源供热；
- 推进供热计量改造和按热量收费；
- 推进城市更新、老旧管网改造和基础设施生命线安全建设。

这些要求对应本项目的热源替代、管网改造、储热、配电、建筑改造、可靠性和成本可负担性模块。

### 2.2 “十五五”碳达峰行动方案

[《“十五五”碳达峰行动方案》](https://www.mee.gov.cn/zcwj/gwywj/202607/t20260714_1161655.shtml)进一步提供了可用于模型设计的行业信号：

- 到2030年，非化石能源消费占比达到25%；
- “十五五”期间单位建筑面积直接碳排放降低3%；
- 在不影响供热的前提下推动北方热电联产机组热电解耦，并支持热电厂建设储热设施；
- 推进燃煤锅炉清洁替代；
- 推动建筑用能电气化和低碳化，提高建筑可再生能源消费比重；
- 加快供热、制冷系统绿色低碳转型，升级集中供热管网并合理配置储热蓄冷；
- 深入推进供热计量改革；
- 电力需求响应能力达到最大用电负荷的5%以上。

其中，17%、25%、3%、5%分别属于宏观、能源系统、建筑行业和电力系统口径。V11 不把这些数值直接等同于单个供热项目目标，而是通过政策画像标记其作用层级和使用条件。

## 4. 代码层升级

### 4.1 政策画像与来源治理

新增 `src/heatplan/policy_alignment.py`：

- 校验政策画像的ID、适用期、来源URL、目标代码和评估模式；
- 区分 `contextual_reference`、`conditional_proxy`、`project_kpi`、`qualitative_mapping` 和 `implementation_gap`；
- 只有 `project_kpi` 目标可以自动给出合规/不合规判断；
- 国家宏观目标只输出“国家参考”，不对项目直接判定合规；
- 将政策目标、模型KPI、实际值、差距、状态、来源和口径限制输出为CSV/JSON。

国家参考画像位于：

```text
data/policy_profiles/national_15th_fyp_reference_2026.yaml
```

### 4.2 非化石热独立核算

V10 的 `clean_heat_kwh` 包含余热和可再生热，适合描述广义低碳供热，但不等同于国家能源统计中的非化石能源。

V11 新增 `non_fossil_heat_kwh`：

- 工业余热仍进入 `waste_heat_kwh`，不自动计入非化石热；
- 可再生燃料或直接可再生热默认按100%计入；
- 可再生源热泵默认只计入环境热部分 `1-1/COP`，压缩机用电继续进入电力和碳排账本；
- 允许使用经审计的 `non_fossil_heat_fraction` 覆盖默认比例；
- 新增 `minimum_non_fossil_heat_share` 项目约束。

因此：

```text
清洁热 = 余热 + 可再生/环境热等广义低碳供热
非化石热 = 可再生燃料、环境热和其他明确非化石热量
```

两者不再混用。

### 4.3 相对基线减排约束

新增项目级相对减排配置：

```yaml
policy:
  baseline_emission_intensity_kg_per_kwh: 0.120
  minimum_emission_intensity_reduction_fraction: 0.17
```

模型自动形成：

\[
E_{CO_2} \le I_{base}(1-r)D.
\]

两个字段必须同时提供，基线必须为正，减排比例必须位于 `[0,1]`。这里的17%只有在地方项目采用相同供热碳强度口径并正式分解任务时才能使用；国家GDP碳强度不能直接代入。

### 4.4 建筑面积直接化石排放

新增：

- `direct_fossil_emissions_kg_per_year`；
- `served_floor_area_m2`；
- `direct_fossil_emission_intensity_kg_per_m2`；
- 直接排放绝对强度上限；
- 相对2025基线的直接排放降低比例。

示例：

```yaml
policy:
  served_floor_area_m2: 1000000
  baseline_direct_fossil_emission_intensity_kg_per_m2: 8.0
  minimum_direct_fossil_emission_reduction_fraction: 0.03
```

没有审计基线和服务面积时，配置校验会拒绝启用该约束。

### 4.5 数值和边界增强

- 纯LP求解时 HiGHS 可能返回空的 `mip_gap`，V11 统一转为 `NaN`，避免摘要生成失败；
- 新增比例、相对基线、建筑面积、非化石分类和直接排放因子的有限性与边界校验；
- 新增政策对齐独立CLI；
- `run_reality_calibrations.py` 增加非化石热和直接化石排放输出；
- 包版本升级为 `11.0.0`。

## 5. 报告层升级

V11 报告不再使用“符合十五五”这类无法审计的笼统表述，而输出四层证据：

1. **国家参考**：原文目标、来源、发布日期和政策层级；
2. **项目映射**：对应模型变量、约束、KPI及未实现模块；
3. **项目结果**：实际值、项目目标、差距和合规状态；
4. **口径声明**：哪些指标只能作为参考，哪些需要地方分解和审计基线。

政策对齐命令：

```powershell
$env:PYTHONPATH = "src"
python -m heatplan.policy_alignment_cli `
  --summary outputs/v11_policy_alignment/scenario1_urumqi/summary.json `
  --profile data/policy_profiles/national_15th_fyp_reference_2026.yaml `
  --output outputs/v11_policy_alignment/scenario1_urumqi/audit
```

三场景统一复现：

```powershell
$env:PYTHONPATH = "src"
python scripts/run_v11_policy_alignment.py
```

## 6. 三场景V11结果

| 场景 | 清洁热占比 | 非化石热占比 | 余热占比 | 化石热占比 | 碳强度 kg/kWh | 最坏情景缺供率 |
|---|---:|---:|---:|---:|---:|---:|
| 乌鲁木齐既有大网 | 75.00% | 18.58% | 38.44% | 15.87% | 0.03857 | 0 |
| 固原分散供热 | 89.91% | 73.80% | 0 | 0.70% | 0.08244 | 0 |
| 武汉冷热联供 | 99.92% | 79.63% | 0 | 0 | 0.10979 | 0 |

结果说明：

- 乌鲁木齐清洁热占比明显高于非化石热占比，主要因为工业余热被单独核算，证明拆分口径是必要的；
- 固原主要依靠可再生/环境热和生物质体系，化石热仅承担极小比例；
- 武汉供热侧无化石热，但系统碳强度仍受购电排放影响，因此“零化石热”不等于“零碳”；
- 三个场景的正常及最坏情景缺供率均为0，低碳转型没有以降低服务可靠性为代价。

上述数值是公共代表日模型结果，不等同于城市正式统计值。

## 8. 当前未完成与下一步

### 8.1 明确保留的实现缺口

- 供热计量覆盖率和按热收费机制尚未直接建模；
- 国家宏观能耗/GDP指标尚无城市级一致分母；
- 建筑直接碳排3%需要真实服务面积和2025审计基线；
- 全国非化石能源25%不能直接作为单个城市供热占比目标；
- 8760 h固定投资回放尚需完成三场景正式测试；
- 城市管网GIS、热计量、SCADA和设备厂家曲线仍需补充。

### 8.2 推荐的V11后续迭代

1. 增加供热计量覆盖率、计量热价和用户弹性模块；
2. 用地方“十五五”规划替换国家宏观参考目标；
3. 建立2025基线—2030目标的可审计参数表；
4. 运行三场景8760 h固定投资回放；
5. 对非化石占比、碳强度、能源价格和配电容量开展情景扫描；
6. 形成答辩用“国家战略—地方问题—模型机制—方案结果—风险边界”图组。

## 10. 阶段判断

V11 已将国家战略从“报告背景”提升为可追溯、可配置、可验证的模型输入与评价体系，同时通过严格的口径分层避免政策目标被机械套用。代码层新增功能经过49项测试和三场景求解回归，原有结论保持不变。

当前版本可作为“十五五”供热转型方案比较和政策情景分析的稳定基线，但正式城市结论必须进一步接入地方目标、2025审计基线、完整年度数据和工程实测资料。

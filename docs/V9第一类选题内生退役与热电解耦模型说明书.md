# V9 第一类选题：<br>既有大型集中供热系统低碳化重构
## 内生退役、热电解耦与极端事件保供模型说明书

**适用赛题：** 第一类——既有大型集中供热系统的低碳化重构  
**核心方法：** 多阶段混合整数线性规划（MILP）+ 概率场景/CVaR + N−1校核 + 工程与财务后评价  
**版本日期：** 2026年7月  

重要说明：本说明书中的数值来自可复现实例城市，用于验证算法闭环，不代表任何真实城市结论。正式参赛必须以目标城市热源、管网、负荷、气象、工业余热和电网数据重新标定。

# 一、先回答：三类场景的代码都能实现吗

底层求解器具有通用性，但“通用求解能力”不等于“三套专用方案均已完成”。当前交付状态如下。

| 赛题场景 | 通用能力 | 专用配置与验证 | 当前结论 |
|---|---|---|---|
| 第一类：既有大型集中供热低碳重构 | 热源—管网—负荷—储热联合规划、存量退役、骨干管网保留、余热/热泵/储热、N−1、财务评价 | 已配置六类运行场景、三阶段政策路径、工程后校核并联合求解 | **完整可运行，本版本重点** |
| 第二类：分散式独立供热清洁转型 | 已支持分布式热泵、节点热源、候选管线、容量投资和局部保供 | 尚未加入生物质燃料采购—运输—库存、村镇微网孤岛运行等专用模块 | 可扩展，不能声称已完整交付 |
| 第三类：夏热冬冷新建高品质供热 | 已支持零既有管网、候选拓扑、建筑热惯性、舒适度惩罚、需求响应和多能互补 | 尚需专门标定间歇启停、湿冷气候热泵性能、用户行为和高品质舒适指标 | 可扩展，不能声称已完整交付 |

因此，参赛选题应明确锁定第一类；答辩时可把另外两类作为“同一内核更换数据与模块即可迁移”的通用性证明，而不要把尚未标定的功能包装成结果。

# 二、第一类场景的真实矛盾与建模边界

第一类城市不是从零建设。其难点不是简单增加热泵，而是同时处理五组冲突：

1. 既有骨干管网价值高，不宜推倒重建，但旧网高温、高损耗和水力瓶颈会限制低品位余热利用。
2. 工业余热边际成本低，但存在停产、检修、温度和空间位置不确定性，不能把其额定容量等同于可靠容量。
3. CHP同时服务热、电系统。固定热电比会夸大或低估其灵活性，必须允许背压/抽凝工况在可行域内变化。
4. “少烧化石”与“立即拆除化石机组”不是一回事。存量容量还承担极寒备用，退役路径必须内生优化。
5. 常规年度低碳考核与罕见应急事件保供目标不同。余热全停时允许备用化石或电锅炉增发，但必须做到零失供；不能机械要求该小时也满足常规清洁率。

模型边界包含热源、热网、负荷、建筑热惯性、短周期/跨季节储热、电网接入、可再生电力、政策与财务；不替代详细管网瞬态仿真和地质勘察，而是通过后校核形成规划—工程闭环。

# 三、总体架构

模型采用“规划决策共享、运行决策按年份与场景展开”的两层结构：

- 规划层决定新增热源、储热、电网容量、候选管线、既有管网节能改造、末端低温化和存量化石热源退役。
- 运行层决定各时段各温级供热、CHP发电、管网正反向流量、储热充放、需求响应、建筑热状态和可再生电力分配。
- 场景层覆盖正常冬季、严寒、复合寒潮、低余热高电价、工业余热完全中断和长持续寒潮。
- 后评价层执行水力热力校核、BTES多年性能筛选、MPC滚动调度、样本外蒙特卡洛和项目融资评价。

投资变量跨场景共享，防止模型在每个场景中“临时重建一套系统”；运行变量可随场景调整，符合先规划、后观测、再调度的决策顺序。

# 四、集合、参数与变量

设阶段集合为 $Y$，场景集合为 $S$，时段集合为 $T$，热源集合为 $I$，节点集合为 $N$，管段集合为 $E$，储热集合为 $K$，温级集合为 $G$。

主要规划变量：

- $x_{i,y}^{new}$：阶段 $y$ 新增热源容量；
- $x_{i,y}^{ret}$：阶段 $y$ 退役的既有热源容量；
- $z_{e,o,y}$：管段 $e$ 是否选择口径方案 $o$；
- $r_{e,y}$：既有管段是否节能改造；
- $E_{k,y}^{new}$：储热新增能量容量；
- $G_y^{new}$：配电接入新增容量；
- $u_{n,y}^{LT}$：末端是否完成高温向低温改造。

主要运行变量：

- $q_{i,g,t,s,y}$：热源向温级 $g$ 的供热功率；
- $p_{i,t,s,y}^{CHP}$：CHP电功率；
- $f_{e,g,t,s,y}^{+/-}$：管段双向热流；
- $c_{k,t,s,y},d_{k,t,s,y},e_{k,t,s,y}$：储热充热、放热和荷电状态；
- $Delta q_{n,g,t,s,y}^{+/-}$：需求响应上移/下移；
- $	heta_{n,g,t,s,y}$：建筑等效热状态；
- $w_{t,s,y}^{use}$：被供热系统吸收的本地可再生电力；
- $l_{n,g,t,s,y}^{shed}$：失供热量，仅作为高惩罚安全变量。

# 五、目标函数

联合多阶段目标是最小化规划期折现总成本：

$$
\min \sum_{y\in Y} DF_y\left(C_y^{inv}+C_y^{ret}+C_y^{op}+C_y^{CO_2}+C_y^{comfort}+C_y^{rel}\right)
+\lambda_{CVaR}\left(\eta+\frac{1}{1-\alpha}\sum_s\pi_s\xi_s\right)-V^{salvage}.
$$

其中 $C^{ret}$ 是拆除费用扣除退役后固定运维节省；$C^{op}$ 已扣除CHP售电收入；$C^{rel}$ 对失供给予极高惩罚；CVaR项约束尾部高成本风险。模型另提供排放最小、成本—排放 $arepsilon$ 约束和消融实验接口。

# 六、V9核心改进一：CHP可变热电运行域

V8把CHP发电量写成固定热电比 $p=\rho q$。V9使用线性可行域：

$$
\rho_i^{min}\sum_g q_{i,g,t,s,y}\le p_{i,t,s,y}^{CHP}
\le \rho_i^{max}\sum_g q_{i,g,t,s,y}.
$$

若电力系统要求最低出力，则：

$$p_{i,t,s,y}^{CHP}\ge \underline p_{i,t,s,y}.$$

售电收益进入运行成本：

$$C_{i,t}^{CHP}=c_i^hq_{i,t}-\kappa_i\lambda_t^ep_{i,t}^{CHP}.$$

这样模型能在电价高时适度提高发电、在热负荷约束紧时降低电热耦合刚性，同时仍受最小出力、启停和爬坡约束限制。该改进直接对应“调峰解耦”。

# 七、V9核心改进二：化石热源内生退役

有效装机不再由人工逐年写死，而是：

$$K_{i,y}^{eff}=K_i^{exist}+\sum_{\tau\le y}x_{i,\tau}^{new}-\sum_{\tau\le y}x_{i,\tau}^{ret}.$$

出力约束为：

$$\sum_gq_{i,g,t,s,y}\le a_{i,t,s,y}K_{i,y}^{eff}.$$

退役不可逆，且不得超过原有容量。退役经济项包括拆除成本和固定运维节省：

$$C_{i,y}^{ret}=c_i^{dec}x_{i,y}^{ret}-c_i^{FOM}\sum_{\tau\le y}x_{i,\tau}^{ret}.$$

政策容量走廊约束为：

$$\underline K_y^{fossil}\le \sum_{i\in I_F}K_{i,y}^{eff}\le \overline K_y^{fossil}.$$

上界推动存量替代，下界保留极寒备用。因而“退出多少、先退哪台、何时退出”由全周期经济性、排放、可靠性和替代资源共同决定。

# 八、骨干管网保留与改造

对既有骨干管网，模型默认保留其既有容量，不把其当成可拆除资产；只优化保温、泵耗和换热改造。改造二元变量与实际流量通过McCormick线性化关联，避免出现“花钱改造但不产生节能”或“未改造却享受高效率”的逻辑错误。

管网热流满足节点能量平衡、口径容量、双向流和温度相关输送效率约束。优化完成后，再根据选定口径和峰值流量计算流速、沿程压降、泵功率与热损失比例。若后校核失败，方案不能进入推荐集。

# 九、余热、热泵、储热和可再生电力

工业余热直接利用与余热源热泵分开建模。热泵COP随热源温度和供水温级变化：

$$COP_{i,g,t}=\min\{COP^{max},\max[COP^{min},\eta_i(T_{sink,g}+273.15)/(T_{sink,g}-T_{source,t})]\}.$$

热泵耗电为 $q/COP$。本地风光电只能抵扣实际存在的热泵、电锅炉和循环泵负荷：

$$0\le w_{t,s,y}^{use}\le \min\{W_{t,s,y}^{avail},P_{t,s,y}^{heat}\}.$$

储热满足能量递推、充放功率、效率、自放热和边界闭合约束。跨季节储热另通过多年BTES模块检验地温漂移、年际热损失和长期可持续性，避免用单日循环SOC冒充跨季节储热。

# 十、常规低碳目标与应急保供目标分离

本版本新增 `transition_target_scenarios`。清洁热占比、化石热占比、碳强度等年度转型指标在正常冬季、严寒、复合寒潮和低余热高电价场景中考核；工业余热完全中断和长持续寒潮作为独立应急事件，考核零失供、容量备用和成本暴露。

这一处理不是放松可靠性。相反，应急场景仍逐小时满足热平衡，失供上限为零；只是允许备用热源在罕见事件中临时增发，不让年度清洁率约束制造无物理意义的“无解”。

系统容量满足：

$$\sum_i\phi_iK_{i,y}^{eff}+\sum_k\phi_kP_{k,y}^{firm}\ge(1+R)D_y^{peak}.$$

关键热源和关键管段分别执行N−1。系统容量保留25%裕度；管段N−1按设计峰值再保留15%输送裕度。工业余热全停与管段故障分别校核，避免默认两个低概率事故必然同时发生。固定方案复演显示复合寒潮、最大热源停运和骨干管段停运均为零失供。

# 十四、创新点与答辩表述

1. **从“预设退役”升级为“内生退役”。** 同时考虑拆除费用、固定运维节省、替代容量、化石容量走廊和N−1备用，输出可执行的退出顺序。
2. **CHP热电解耦不是口号。** 用可变热电运行域、最低电出力、启停和爬坡描述供热与电力调峰之间的真实耦合。
3. **骨干资产保留有数学约束。** 既有主管网容量被保留，优化对象是节能改造、旁路互联和局部扩容，而非默认推倒重建。
4. **常规转型与应急保供分账考核。** 低碳KPI在政策场景考核；余热全停和长寒潮严格考核零失供，解决“指标很绿但系统不可靠”与“极端小时拖垮全年指标”的双重问题。
5. **规划—工程—运营—财务闭环。** MILP结果必须通过水力热力、BTES多年、MPC、样本外和融资评价，增强实用性与可行性。
6. **诚实的通用性。** 同一数据结构可迁移到另外两类，但明确列出尚需开发的生物质物流、微网孤岛和湿冷舒适度模块，避免过度宣称。

建议答辩主句：**我们不是简单用热泵替煤，而是在保留北方城市骨干热网资产和极寒保供能力的前提下，让模型自主决定余热、储热、可再生电力、管网改造与化石机组退役的最优时序。**

# 十五、数据替换与正式参赛前验收

正式应用至少需要：逐时分区热负荷与室外温度、热源容量和效率、CHP工况域、工业余热温度/流量/停产计划、管径长度粗糙度与泵站、电网接入容量与分时电价、风光可用电量、储热地质与换热参数、投资运维拆除费用、碳因子、热价与融资条款。

验收条件：

1. 质量与能量平衡误差在容许范围内，所有政策约束可追溯到输入文件。
2. 正常、寒潮、余热中断及N−1结果均报告，不隐藏无解场景。
3. 管网水力热力后校核无 `fail`；备用联络线的建设理由单独说明。
4. 退役结果满足容量下限、退役上限和不可逆性。
5. CHP电出力始终位于热电比上下界之间。
6. 财务指标包含热价、回收率、债务、税收、补贴和盈亏平衡热价敏感性。
7. 使用目标城市数据重新求解并开展参数敏感性，不直接引用本说明书示例数值。

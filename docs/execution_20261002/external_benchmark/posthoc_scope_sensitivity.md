# 事后范围敏感性分析

这是读取预注册实验结果后，由统筹明确追加的 `posthoc_scope_sensitivity`，不是原协议中预注册的主要比较。原因是 13/24 个案例年度的原始有效小时峰值不在保留完整日范围。原协议、名单、原始结果和锁均不更改，不重新运行选择或校准，不调参。

对已得到的每法 `K=max(代表小时平均kW)`，扩大**诊断参考范围**至本年全部有限非负计量小时。温度不作本次范围准入条件，缺测计量仍排除、不补零。保存有效观测小时数、覆盖率、部分观测能量、观测峰值、K/观测峰值、`max(load-K,0)` 欠覆盖小时数/率和 kWh/能量率，并和原保留完整日范围并列。没有成功方法 K 的失败记录继续显示为 unavailable。

这仍是部分观测年的 capacity-only 数学参考，不是完整全年真实值、设备容量设计、可靠性验证或 HeatPlan 运行。扩大范围不改变代表日法的预注册指标；新增输出均显式标为事后分析。

复现：`python scripts/bdg2_benchmark_diagnostics.py analyze`。该侧车脚本另汇总同一选日的校准前后配对，以避免将 23 个校准成功案例中位数与 24 个未校准案例中位数误作同样本比较。

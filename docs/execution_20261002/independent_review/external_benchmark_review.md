# BDG2 基准独立验收

结论：已独立核对当前冻结版本的实际数据、样本、指标及事后范围分析，未发现数值或来源连接错误。基准可用于所声明的外部热计量压缩实验；不能据此宣称工程可靠性、预测效果或中国三城节能。

## 实际执行与版本

复算入口为 `recompute_external_results.py`，证据为 [完整复算 JSON](support/external_recomputation/results.json)。复算没有 import 基准适配器或核心，也没有重跑聚类、校准、模型拟合或工程求解。直接重新读取原 metadata/weather/三类 cleaned CSV，独立重建日历、缺测退出日、样本顺序和全部指标。Wasserstein-1 用两个经验分布 CDF 差值的精确积分另行计算，没有调用原脚本的 scipy.stats.wasserstein_distance。

- 5 个实际 CSV SHA256 匹配冻结来源；协议、适配器、测试、清单、环境及源审核锁有效。
- 原清单的 12 个通道通过稳定 ID 规则独立再生；覆盖、完整日、原峰值退出标记等 24 例年度质量信息逐项核对。
- legacy 快照 `8922b290663584ca477d4997702158389a99e22945b1878c8c548e925edaf5a1` 与 new_core 快照 `5c18ae1a3a37a8f0adc1ec4ea810988848669be6fe56f4f532b1339db225e131` 分别匹配版本锁；legacy 48/48、新版 71/72 成功。
- 独立复算全部 119 成功方法记录、5,920 条真实爬坡尾部事件，核对实际日期、计量值、权重、同 M 对照、三次已保存计时及中位数。另核对 120 条事后范围记录（含失败），以及图表共同 23 个正能量案例的所有显示中位数。共 37,077 次标量比较、39,537 次检查，无差异；检查数量不代替使用范围判断。
- 唯一失败为 `chilledwater__Bobcat_assembly_Camilla / 2017 / extreme_calibrated`。该年有效保留计量能量实际为 0，校准无有效能量列；原记录、无定义比率和事后 unavailable 均保留，未用零冒充成功。

极端锚点保留峰值和最大事件，但普通方法在本样本的能量和分布中位数更好。权重校准对 23 个成功配对都降低能量偏差，对 W1 有 15 例改善、8 例恶化；普通方法 W1 中位数仍优于两种极端方法。校准只用本年观测总量，其小残差不能作为留出预测效果。

独立用每个代表日能量、总权重和极端下界推导一维精确匹配能量区间，23 个非零目标均在可行区间内。实际小残差与正则软目标一致。这不关闭一般多列不可行目标的 IR-004 后续采用诊断建议。

最大午夜事件的修订实际改变了 `chilledwater__Bull_assembly_Beau / 2017` 一例：旧版没有同时保留端点日，新版保留；M 由 9 增到 10。不能把它解释为相同预算下的纯改进。其余 23 例极端选日一致。选中原事件端点只保留信息，未建立跨日运行约束。

完整日筛选保留 274–364 日、完整日覆盖 75.07%–99.73%；13/24 例原始有效观测峰值被完整日范围排除。因此，极端方法在保留范围的 capacity-only 欠覆盖为零，是峰值锚点的预期性质，不能泛化为所有观测或工程全年。

事后分析清楚标为 posthoc，未改原协议/选择/权重。直接从原计量独立复算全部有效非负小时后，新版 extreme_aware 的 13/24 例存在欠覆盖；峰值保留中位数约 99.57%。数据缺口未补零，温度不作为该侧车准入条件。它依然是部分观测范围的无储能容量数学诊断。

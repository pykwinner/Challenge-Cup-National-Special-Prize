# 三城空间参考独立验收

结论：三城实际选择、原生道路响应、图结构、吸附和全部路线状态独立复算一致，可以交付为空间参考实验。它们尚不是供热管网、热源选址或开挖许可证明。

复算入口为 `recompute_spatial_results.py`，完整证据见 [复算 JSON](support/spatial_recomputation/results.json)。复算没有 import `osm_reference.py` 或构建脚本；从原 CSV 重做固定选点/选路，从保全 API 原响应重建全部 node refs、逐段米制长度和拆分图，再独立计算最近道路线段与 Dijkstra 距离。未联网重取，未改原 CSV，没有工程求解。

三城 18 个建筑的原 CSV 稳定排序和 98 个道路 way 完全匹配冻结清单，6 次保全 API 响应 hash 与请求范围匹配；全部 766 个原生节点及 801 个原始段重建完备。33 个原 CSV/旧审核文件实际 SHA256 再次匹配先前记录。共 1,909 项检查无差异，复算期间所用代码和产物 hash 未变。

全部 18 个最近线段、吸附距离、同段拆分守恒、导出节点/边、连通分量、15 个目标路线状态、12 条成功路线长度与绕行比均核对。固原三个失败目标的独立最近距离约 209.32m、185.45m、175.02m，确实超过 150m；失败并未被重选或删去。固原第一条成功道路段路线约 3398.04m，加两端质心连接约 3603.65m，与文件和图示一致。

所有实际道路共享节点按真实 OSM ID 重建；本批次没有内部共享 node 的层级冲突，不能把“未出现冲突”解释为已实证覆盖所有桥隧异常。地图三张 PNG 已直接查看，编号、失败红叉、图例、米制坐标与参考用途说明可读。PDF 由空间执行者另行渲染检查，独立审查没有重做 PDF 渲染。

保存完整 way 的窗口外部分没有伪称被裁剪：最大顶点距固定中心为固原 3411.85m、乌鲁木齐 1320.73m、武汉 2760.53m。选区半径 1.5km 是道路相交与建筑筛选规则，完整道路延伸范围另报，符合协议。

逐段投影/测地线距离从原 node 坐标重新计算，数值一致；仍使用同一 pyproj.Geod 库，所以是独立数据与程序复算，不是第二套测地算法或测绘精度认证。建筑和道路导出异时、未知访问条件和未经官方认证的边界均明确保留。

`model_interface.json` 中真实供热用途、供热面积、热损失/容量、需求、实际管长/管径/容量/效率/费用均为 null，工程准入为 false。当前结构无法直接替代正式 HeatPlan 物理配置。隔离 `_runtime_packages` 在原交付说明中排除，独立审查只读使用其中已有 pyproj，未安装或交付依赖目录。

## 三项最有价值的下一步

1. **统一物理时间和观测边接口。** 优先修 IR-001，并把 IR-002/003 纳入相同接口约束。source_time/timestamp/time 的优先级已修；显式 source_time 不是可解析时间时应继续拒绝。旧整数 time 的 multiyear 兼容应由 builder 不伪造 source_time 来保留。完整年、明确供热年度与演示的 24h 块分别声明身份；当前 builder 文案与 dt=1 准入已改，不再把接受部分块本身列为 bug。

2. **保留软权重校准，增加采用条件。** 当前求解器正确执行带正则的软能量拟合、总天数守恒与极端日权重下界。解析反例中目标 a/b 能量各 120，而两个代表日的总贡献固定 480；精确匹配需要权重各 0.5，与权重和 2 冲突。SLSQP 合法成功，能量偏差仍各 +100%。因此 solver_success 仅证明优化成功，不能证明能量准确。可另给精确匹配可行性、绝对/相对残差及预先固定的采用阈值；不应为了过门槛改变样本或补造负荷。对矩阵 M、目标 b、下界 l、权重和 W，精确匹配存在当且仅当 b 属于 M l + (W−1ᵀl) conv{M 的列}（W≥1ᵀl；这是本审查的线性代数推导）。当前 JSON 已诚实标为 soft_regularized_least_squares，并保留采用前覆盖、投资稳定和固定投资回放的 caveat。

3. **把极端日覆盖与实际运行可行性分开验证。** 外部真实计量的 capacity-only 欠覆盖与完整原始事件命中可以作为有限诊断；不能代称 HeatPlan 可靠性、RC 校准或节能。当前日状态仍各自闭合，保留午夜两侧原日期只保留信息，未创建日间运行约束。季节状态分解属于后续功能；本批次不要求新建模型或工程求解。

## 论文对应与实现边界

- [Kotzur 等（2018）](https://arxiv.org/pdf/1710.07593)，§2.3，PDF 第 7–8 页，式 13–14：需保留原始日到代表日映射、inter-period 状态递推及重构状态容量约束。常系数情况下可写 x(i,t)=a^t x_inter(i)+x_intra(f(i),t)，x_inter(i+1)=a^T x_inter(i)+x_intra(f(i),T)。代表日权重与各日独立循环不构成该分解。现有 1R1C exact ZOH 不应换成论文储能示例的离散近似。
- [Teichgraeber 等（2020）](https://arxiv.org/pdf/2002.03059)，§2.3–2.4，PDF 第 4–6 页：统计极端预选与固定设计后完整运行反馈迭代是不同程序。用松弛暴露失供，再添加对应极端日直至停止条件满足；逐日独立检查的可分性不适用于季节储能或年度碳约束。当前代码仅有统计锚点，不能称已实现该迭代。
- [Teichgraeber、Küpper、Brandt（2021）](https://optimization-online.org/wp-content/uploads/2021/08/8558.pdf)，§2.2–3.2，PDF 第 3–5 页，式 8–11：停止标准与失供总量相关，碳超限另有松弛项；没有失供不同时证明碳排放合规。应分别报告运行约束和各自停止条件。
- [Teichgraeber、Brandt 时序聚合综述（2022）](https://optimization-online.org/wp-content/uploads/2022/01/8753.pdf)，§6.4.1，PDF 第 16–17 页，式 5–6：聚类划分与代表样本选择分开。固定簇的最近质心样本也是平方 L2 总和的最优实样本，因为 Σ||x−z||²=Σ||x−c||²+n||z−c||²。因此代码宜称 KMeans 划分 + 最近质心实样本；它不是重新优化划分的 k-medoids，也不是未平方 L2 的 medoid。解析样本 [0,0,0,4,10] 选 4；未平方 L2 选 0。低统计误差不独立证明运行可靠。

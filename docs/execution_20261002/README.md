## 本轮选择的依据

- Teichgraeber 等（2020），[极端时段研究](https://arxiv.org/abs/2002.03059)：固定统计极值只能作为起点，优化约束的失配可用于进一步选择时段。
- Teichgraeber 与 Brandt（2022），[时序聚合综述](https://optimization-online.org/wp-content/uploads/2022/01/8753.pdf)：统计指标与规划结果要分开检验，固定投资后用原时序验证。
- Kotzur 等（2018），[季节储能时序聚合](https://arxiv.org/abs/1710.07593)：跨周期状态需要明确的联系。本轮保留极端事件两侧实际日并不等于新增跨日储能状态约束。

上述是方法依据，不把论文中的改善比例作为本项目实验结果。数据集实验使用原始计量数据；小规模反例单元测试会明确标为人工测试夹具。

## 评分证据目标

系统架构：可复现数据适配与实验入口；动态特性：峰值/真实相邻小时爬坡；情景适配：三个城市各有空间参考；多目标：本轮不以统计基准冒充成本碳排放前沿；多尺度：建筑节点到道路的可追踪映射；可视化：三城地图及基准图表；代码质量：边界反例、来源哈希与独立复核。

尚未获得真实设备性能、资产容量、计价与运行观测时，空间参考不会被写成真实热网设计，国外 BDG2 不会被写成三城市实测。

# 官方数据替换清单

拿到完整题面后，先建立统一数据字典。所有功率统一为 kW，热量统一为 kWh，价格统一为元/kWh，碳排统一为 kgCO2。

## 城市与负荷

- 热力站/小区/建筑节点 ID、坐标、建筑面积和末端类型；
- 供暖季逐时负荷或室外温度、建筑类型、面积等负荷估算字段；
- 高温散热器、低温地暖/风机盘管比例；
- 室温上下限、可移峰比例、允许持续时间和回弹参数；
- 极端设计温度与负荷安全系数。

## 热源

- 位置、热源类型、可供温度、现有容量和扩容上限；
- 逐时/逐月可用率；
- 投资、寿命、维护、燃料/购电成本；
- 效率或 COP 曲线、最小出力、爬坡、启停；
- 直接排放因子和上游排放因子；
- 工业余热停产检修和资源不确定性。

## 管网

- 现有管线起终点、长度、管径、设计流量、保温和热损；
- 道路/河流/铁路等候选通道与禁建边；
- 各管径单位造价、容量、泵耗和寿命；
- 供回水温度、压降、泵站和换热站容量；
- 是否允许双向热流、环网和备用通道。

## 储热

- 类型（水罐、PCM、BTES）、位置和现有容量；
- 单位投资、寿命、占地；
- 充放效率、自损失、功率-容量比；
- PCM 状态相关充放曲线；
- BTES 土壤参数、井深、间距和季节边界条件。

## 外部时序

- 室外温度、风速、太阳辐照；
- 分时电价、燃气/煤/生物质价格；
- 电网逐时碳排因子；
- 工业余热和可再生热可用率；
- 典型年、寒潮年和资源低谷年。

## 最少需要确认的题面口径

1. 规划年限、折现率和价格是否含税；
2. 是否允许供热缺额，若允许其惩罚或可靠性标准；
3. 碳排是否含设备制造和上游能源；
4. 管网是否必须连通所有用户，是否可选择不接入；
5. 三个场景是分别求解还是统一模型下比较；
6. 结果评分是按固定权重，还是只要求展示 Pareto 解；
7. 是否提供 GIS/8760 小时数据及允许使用的外部数据。

# 数据与外部验证审视：现有资产、准入边界与最小补强

审查日期：2026-10-02（北京时间）。本轮只读原资料、配置、来源登记和实验，不改源数据、核心、冻结实验、论文/PPT，不新开代理。唯一新文件为本报告。这里的实验和门槛是下一轮建议，未冒称本轮已经执行。

**数据侧结论：不能笼统说“热源、费用、管道、围护、电价、排放全缺”。已有数据主要缺少同一项目、同一对象、同一时间和计费边界的关联证据。来源完整的外部计量/空间实验已有成果；三城正式主案例必须先过E0逐字段准入，旧synthetic数值只可用于明确隔离的程序/数学诊断，不因标注假设便取得正式模型或经济效果资格。** 三城现场物理验证仍不完整；海外计量算法测试不能替代三城物理验证。优先用有真实依据的字段完成一个闭合案例，再以连续运行检验把统计压缩优势转化为规划/运行证据，收益高于继续无差别扩充数据目录。

## 可引用与不可引用

**按条件可引用的输入：** 2023 年湖北、宁夏、新疆 3 个省级电力平均排放因子；NASA 三城市 2020–2024 年的 15 个完整年度文件、每文件 4 个原始产品列。当前正面准入合计 63 个字段记录，须匹配文件 SHA256、字段、数值和适用口径。NASA 增量复核独立比对 131,544 小时、526,176 个数值，全部一致；其 60 个列记录覆盖原账本中同 ID 的旧核验状态，见 `weather_field_addendum.json`。原列 `solar_irradiance_kwh_m2_hour` 实际单位是 **Wh/m²**。它们是 NASA 格点产品、时钟为 LST，接电价/占用前仍须明确民用时钟转换。2023 年原登记只有 reused_existing_file，本次查询根据同城市 2024 坐标重建，不能倒填历史 API 版本或获取日期。

**可作为公开实测试验研究引用：** Fraunhofer Annex71 德国 Holzkirchen N2 实验楼。11,988 行的 7 个数值列已从原始工作簿全量复算，4 个时间/身份列已核对；范围见 `delivery_policy.json` 中独立的公开试验白名单。必须注明室温是房间传感器按面积加权的派生均值，电加热是电输入，部分得热拆分由发布者按计划处理，太阳列是辐照代理，发布者对短缺测有填补且没有逐行标志。拟合 H/C、参数边界和时段端点约定不能写成源文件认证的武汉物性。CC BY-SA 4.0 归属要求须保留。

**可作设计情景的条文引用：** 武汉 2024 征求意见稿的特定条款、湖北 2024 分时政策的适用资格/倍率。草案不是已核实的现行有效强制规范；表 7.4.8 的性能指标是 **ACOP**，不是 EER。分时政策没有给出合成 0.30–1.12 元/kWh 的绝对电价曲线，也不能覆盖 2023 历史账单。出处、页码、单位和排除范围见 `PROVABLE_SOURCES.md`。

**不可作为真实工程输入/收益证据引用：** C1 面积、H/C 基数、内部/太阳得热、占用、舒适阈值和合成冷热负荷；当前设备投资、运维、COP/EER、寿命、折现率、碳价及未证实容量；C3 示意坐标、假设比例尺、路线阈值和合成管价；来源目录中尚未逐参数复核的其他主张。保留历史文件，明确标为算法测试样例并从正式实验选择中剔除。任何求解成功、年度回放或成本降低均不能替这些输入完成认证。

## 优先补证

| 优先级 | 参数族 | 解除缺口所需材料 |
|---|---|---|
| P0 | C1 面积、H/C | 建筑台账/图纸及面积口径，构造材料或实测辨识原数据、单位、边界与校准验证 |
| P0 | 得热、占用、温度、负荷 | 实测或具体公开试验原字段；若作为设计协议，明确协议而非实测，并检查每个物理基数 |
| P0 | 绝对电价 | 客户类别、容量、月份、合同/代理购电基价、税费输配分项与适用时段 |
| P0 | 投资、运维、COP/EER、寿命 | 指定设备型号/工况的原表或报价，价格年与工程边界；不同指标不能互换 |
| P0 | 折现、碳价、容量 | 有出处的场景/设计协议与适用边界；现场资产/场地容量须现场证据 |
| P0 | 空间及管网 | 测绘/GIS/合法路线/障碍及产权条件，实际管道规格与工程报价 |
| P1 | 地源热平衡 | 有效版本、适用建筑与规模、比值方向、地下勘察/热响应和长期模拟；单年比例不能证明长期稳定 |

H/C 的复算公式分别为 `area_m2 × heat_loss_w_per_m2_c / 1000` 和 `area_m2 × effective_capacity_wh_per_m2_c / 1000`。公式正确不能证明面积与强度值真实。C1 太阳得热的 `0.015` 因子、得热系数、占用规则、温度分档和峰值负荷仍缺逐项证据。

## 文件与复核

- `field_ledger.json/csv`：逐字段/列来源、URL、本地原件、SHA、单位、时间、地域、具体位置、直接/公式与缺项。
- `weather_field_addendum.json`：60 个原 NASA 产品列的独立增量核验，覆盖同 ID 的快照旧状态；不批准派生负荷。
- `source_review.json`：4 份逐条已读官方材料；`source_evidence.json` 同时保留未审核目录主张及 N2 原件身份。
- `delivery_policy.json`：正面白名单、其余排除记录及独立公开试验范围。任何不在正面名单内的项目物理输入都须补证。
- `PRIORITY_GAPS.md`、`priority_gaps.csv`：主要阻断结论与逐条缺口。
- `outputs/competition_20261001/C3_data_truth/`：摘要、结果身份、N2/NASA 独立比对、自检、最终校验和完成 manifest。

最终验收只证明审计文件可读、记录覆盖与来源/结果身份一致；**不证明项目所有数据已真实化，也不解除建筑、经济和空间参数阻断。**

# C1 独立外部实测 RC 验证交接

本轮找到了可下载、许可明确、具备室内温度、室外温度和实际电热输入的公开实验数据，完成独立的预登记辨识与留出验证。**当前单状态 1R1C 的长程适用性不足：训练持续开环 RMSE 为 4.808256℃，测试持续开环 RMSE 为 1.885259℃，相应温度持续基线分别为 1.174283℃、0.790172℃。** 一步误差的小幅改善不构成长程预测或物理模型通过验证的证据。

数据发现、方案登记及主计算沿用任务日期 2026-10-01；最终交接与哈希核对于北京时间 2026-10-02 完成。模型、损失、数据划分与初值没有因留出结果不利而更换。

## 来源、许可与实测边界

采用 Kersken, Matthias; Strachan, Paul (2020), *Twin House Experiment IEA EBC Annex 71 Validation of Building Energy Simulation Tools - Specifications and dataset*, version 2，Fraunhofer IBP / Fordatis，德国 Holzkirchen N2 电加热试验房。[机构发布页](https://fordatis.fraunhofer.de/handle/fordatis/161.2?locale=en)，[DOI 10.24406/fordatis/76.2](https://doi.org/10.24406/fordatis/76.2)。机构页面明示 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；选定原数据和派生数据、轨迹、图表保留该许可及上述署名，并注明变换。作者没有为本项目方法或结果背书。

原主试验 ZIP：[下载地址](https://fordatis.fraunhofer.de/bitstream/fordatis/161.2/4/03_Data_Main_Experiment.zip)，46262744 字节，SHA256 `832754489e0c513c8cb09b7e43d61a9f5249ff5502a781a672cae6d588a876a1`。原实验规范：[下载地址](https://fordatis.fraunhofer.de/bitstream/fordatis/161.2/2/01_Experimental%20specification%20BESmodVAL_annex71_final_v1_0.pdf)，7110681 字节，SHA256 `0cfdc5d5a0a73362b4195ed53c5ca95493c7b2a50c64d10a14403047f73d5180`。下载日期、URL、尺寸与哈希均存于 `evidence/downloads.json`。

实际拟合读取 `Twin_house_N2_exp1_full1_10min.xlsx` 和 `Twin_house_weather_exp1_10min_compensated.xlsx`。原 ZIP 使用 Deflate64 方法 9；普通 zipfile 不支持，最终使用已安装的 inflate64 读取指定成员，并核验解压后尺寸、CRC 和 SHA256。没有重打包或改写原发布 ZIP。

这里的“实测”指**发布者处理过的实验测量**。规范 6.2 明示短时故障温度线性插值、功率/流量置零，未附逐行质量旗标；这些填补行的数量无法独立恢复，不报告为零，也不能声称每个值均未经处理。仅选 N2，排除 O5 的仿真功率补齐。设计好的实验用户/设备使用安排不等于虚构传感器测量。

十个房间中心、1.1m 高度空气温度按规范 Figure 9 地板面积加权，总面积 165.75m²。这是派生的传感器空间平均，不能称为直接测得的全屋容积均温或时段末温度。房间电热功率和 IHS 输入相加，W 转 kW；部分列由发布者拆分，两列相加恢复总电热输入。电功率到房间显热采用系数 1 是本模型假设。未使用设定温度替代室内实测，也未使用计算的生活热水、热泵功率或水流功率。

室外温度与辐射取现场天气表。同一窗水平及四向立面辐射最大值除以 1000 为太阳代理输入，单位 kW/m²；其系数为有效面积，不冒称实测透窗太阳得热。窗玻璃面积 16.77m² 与供应商 SHGC 0.62 给出有效面积上限 10.3974m²。H/C 边界是分析者的宽正值约束，不是源数据实测物性。

发现阶段还下载了 DTU CTSM-R Building 2 作者例子，但 ZIP 无许可声明，太阳辐射正文/图示单位不一致，未用其拟合；公开交付包应排除本地 `ctsm_*` 发现文件，直至许可明确。Strathclyde Annex 58 的机构页许可明确，但文件访问返回 HTTP 403，未获得可分析文件。既有研究 PDF 仅只读，不属于本轮改动。

## 时间、划分与预测定义

全时段 11988 行连续 10 分钟记录：原固定 CET/UTC+1 标签 2018-12-07 18:10 至 2019-03-01 00:00，对应 UTC 2018-12-07 17:10 至 2019-02-28 23:00。两表 DATE 标签逐行完全匹配；选定字段无非有限值、时间重复或缺间隔。没有重采样、用户插补、随机切分、按误差裁剪或拟合选择功率移位。

首行 18:10 相对实验开始 18:00 支持窗末标签推断，但平均窗的绝对相位未被发布者明确确认。各变量均按同标签区间平均处理；采用常输入 RC 解的积分观测公式，不把平均温度当作时段末状态。

| 段 | 预测目标行（零起点，含首不含末） | 目标数量 | 首个 UTC 标签 | 最后 UTC 标签 |
|---|---|---:|---|---|
| 训练 | [1, 7192) | 7191 | 2018-12-07 17:20 | 2019-01-26 15:40 |
| 验证 | [7192, 9589) | 2397 | 2019-01-26 15:50 | 2019-02-12 07:10 |
| 测试 | [9589, 11988) | 2399 | 2019-02-12 07:20 | 2019-02-28 23:00 |

首行仅作初始化。模型为 `C·dT/dt = H·(Tout−T) + Q + A·I`；只最小化训练一步预测 SSE，4 个确定性初值只按训练 SSE 选择，验证和测试不参与拟合或选择。一步预测每窗读取上一窗温度观测；持续开环从全记录首窗初始化一次，此后不读取温度观测；分段开环在每段开始从前一窗观测初始化一次。每种基线按同样信息方式保持温度。所有方式使用已经记录的天气与电热输入，属于条件预测，不能称为可部署的未来天气/控制预测。

## 运行、测试与结束状态

在工程根目录运行：

```powershell
python scripts/validate_external_rc_benchmark.py
python -m pytest tests/test_external_rc_benchmark.py -q --basetemp=outputs/competition_20261001/C1_external/pytest_final
```

最终测试结果 **14 passed in 7.64s**。检查包括原发布文件/成员身份、全部行的时间与单位、6 类坏数据拒绝、连续顺序划分、区间平均公式与独立积分对照、开环不读取后续温度、一步只读取过去温度、训练拟合不读取留出温度、全部误差由 CSV 重算，以及主要输入/输出哈希。测试中的解析夹具只验证程序，不计作外部实测证据。测试通过证明实现与记录的一致性，不改变模型长程表现不佳的结论。

首次普通 ZIP 提取失败后采用带 CRC 校验的 Deflate64 读取；尝试安装 zipfile-deflate64 曾因编译环境缺少 io.h 失败，未作为运行依赖。当前已提取的两个源 XLSX 有完整身份记录，正常复跑不需重新下载或安装该失败包。PDF 用已有工作区运行时只读提取和目视检查。

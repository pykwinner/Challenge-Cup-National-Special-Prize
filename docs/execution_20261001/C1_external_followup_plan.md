## 研究问题与唯一损失选择

研究问题：在相同 1R1C 结构、数据、边界、初值和求解设置下，仅将训练目标改为**固定 24 小时分块开环预测 SSE**，能否改善已记录输入条件下的持续与分段开环表现？

## 24 小时分块损失的精确定义

每窗 `Δt=1/6 h`，每日预测长度固定为 144 窗。训练块锚点按行号固定为 `s=0,144,288,…,7056`，不按自然日对齐或误差调整。每块预测目标为 `s+1` 至 `min(s+144,7191)`，首尾均包含。共有 49 个完整 144 窗块和最后 1 个 135 窗块，7191 个训练目标恰好各计一次，不丢弃末块，也不重复加权重叠窗。

对候选参数，定义 `a=exp(−H·Δt/C)`、`f=(1−a)/(H·Δt/C)`、`E_i=Tout_i+(Q_i+A·I_i)/H`。观测 `M_i` 为区间平均温度。每块仅用锚点区间的观测 `M_s` 反推该区间末状态：

```text
T_end(s) = E_s + (a/f)·(M_s−E_s)
M_hat(i) = E_i + f·(T_end(i−1)−E_i)
T_end(i) = E_i + a·(T_end(i−1)−E_i)
```

块内预测不读取目标窗温度；下一块开始才按固定锚点重新初始化。训练目标为所有块、所有目标窗 `(M_hat(i)−M_i)²` 的总和，单位 ℃²，等权、无终点加权、无残差截断、无异常值剔除。锚点反推随参数变化，必须包含在同一损失计算中，不另行拟合初始状态。

输入 `Tout/Q/I` 仍为记录的条件输入，不解释为提前可获得的天气或控制预测。训练温度用于固定锚点初始化及计算残差；任何验证或测试温度均不得进入训练损失、收敛选择或参数选择。

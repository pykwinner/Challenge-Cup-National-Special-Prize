## 供统筹消费的接口

每城 `candidate_network.json` 包含：

- `candidate_edges`：每段只出现一次，`identity`与`name`等于唯一 `physical_edge_id`，含 `from_node/to_node`、`route_length_m`、`route_length_basis`、`geometry_xy_m`和 `geometry_provenance/route_provenance`。
- `candidate_rules`：列表结构，每项的`pipe`对应边`name`，直接提供 `route_length_m`、`route_length_basis`、非空 `route_provenance`、`physical_edge_id`，与统筹的新显式长度分支一致。
- `paths[].traversals`：有序的`edge_identity`和`direction`（+1从canonical from到to，−1反向）。同一段在多个路径中的引用使用同一ID，不应按引用次数新增管道投资或容量。
- `nodes`：原生/吸附分点或建筑质心参考节点及米制坐标。零长度建筑连接不另造一段，而登记端点别名。未连通但吸附成功的建筑仍保留孤立端点身份。
- `failed_paths`、`buildings`和`validation`：全部建筑身份及失败对象、逐路有向连通检查、独立重算的唯一段长和引用账本。

规则中的 `connection_allowed`保持`null`，不主动许可建设。当前规则片段不能单独作为完整预处理/求解输入：还需真实项目对象与参考节点的映射、片区/系统归属、许可与距离限制、合法温级、物理参数和工程费用依据。预处理要求显式布尔许可；回归已验证未补许可时会拒绝。

节点坐标为WGS84 UTM的投影米，EPSG见每城来源清单；接入`local_cartesian_m`时可整体平移到声明的本地原点，必须对所有节点统一变换并记录。不能重新对路径端点乘`route_factor`覆盖段长。路径总长只能用于展示/可达性核对；模型建设应按唯一段`name`建立一条候选边，经过共享段的热流在对应节点平衡中汇集。

ID基于案例命名空间、冻结来源清单哈希、端点身份和层级上下文，同一版输入/同批吸附可稳定复现。换源版本、几何或吸附分割应登记新版本，不把它当已勘测管段的永久资产编号。需确实平行铺设两条管路时，要依据设计明确新增物理身份和工程依据；不能简单复制一条共享段。

`geometry_provenance`含原始响应文件SHA、请求URL与采集时刻，边内含原way版本/时间、原segment端点node refs及版本、访问/层级上下文。分批OSM GET不是原子历史快照，缺少层级标签也不是现场同高程确认；吸附点不是已核验建筑入口。锚点仍为第一栋参考建筑，**没有变成热源位置**。

各边的实际管长、DN、容量、热损/效率、流量、泵功率和费用全部留空；建筑实际供热面积、H/C和负荷也留空。`eligible_for_engineering_solver_input=false`、`engineering_admitted=false`。因此本轮证明的是共享几何接口及防重复的计价入口，不能宣称真实热网接入或三城供热运行通过。

## 文件与复现

每城提供 `candidate_network.json`、`candidate_rules.json`、`candidate_edges.csv`、`candidate_edges.geojson`、`path_edge_incidence.csv`和`failures.json`。逐次运行及代码SHA保存到 `runs/`；最新汇总见[results.json](results.json)，验收记录见[verification.json](verification.json)，文件版本及SHA见[manifest.json](manifest.json)。上轮地图和原生来源继续在[冻结空间参考材料](../../execution_20261002/spatial_reference/README.md)，没有覆盖。

在主工程根目录运行：

```text
python -B scripts/build_shared_osm_candidates.py
```

脚本只写 `docs/implementation_20261002/spatial/`及其子目录，校验历史响应和旧审计；不下载数据、求解或修改全局环境。纯接口模块仅用标准库；离线重新投影/求路需上轮已隔离的可选pyproj、networkx。若主环境已有pyproj则优先使用，否则沿用旧隔离目录。移动项目后若原33个输入的旧绝对路径不可用，几何复现仍可用，但汇总会列出缺失文件，不声称已完成原文件哈希复核。

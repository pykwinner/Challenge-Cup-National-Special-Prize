## H/C与服务公式

几何：平面8×6m、高2.7m；南窗2×3×2m，窗12m²；不透明墙面积 `2*(8+6)*2.7-12=63.6m²`，楼地面及屋面各48m²。面积采用原件尺寸，没有放大到虚构片区。

H采用表1-15明确列出的分项UA：

```text
H=(wall32.715 + floor1.892 + roof15.253 + windows36.000 + infiltration18.440)/1000
 =0.1043 kW/K
```

18.440W/K渗透项对应原型海拔1609m。**本次保持这一公开热工原型，不把它称为根据武汉空气密度修正的本地建筑。** 一条H把所有损失集中到室外气温，是模型简化；地面/表面换热及气象替换后与详细BESTEST模型的差异未作外部认证。

C用真实规定层序中室内表面到第一保温层前的材料，集中于同一个温度状态：

| 分项 | A(m²) | d(m) | ρ(kg/m³) | c(J/kg/K) | A·d·ρ·c(J/K) |
|---|---:|---:|---:|---:|---:|
| 墙内侧石膏板 | 63.6 | 0.012 | 950 | 840 | 609033.6 |
| 木地板 | 48 | 0.025 | 650 | 1200 | 936000 |
| 顶棚内侧石膏板 | 48 | 0.010 | 950 | 840 | 383040 |
| 合计 | | | | | 1928073.6 |

`C=1928073.6/3600000=0.535576 kWh/K`。表1-16轻质原型HEATCAP总值1015.912Btu/°F约1.929MJ/K与此内侧口径吻合，存在表中英制/SI舍入差。玻璃、家具、空气及保温之外的木饰面/屋面板未计入集中容量。**这是一阶模型的内侧材料容量近似，不是现场辨识后的有效C，不是把全厚材料质量热容伪装成ISO有效值。** 原报告规定了各层数据，但未替本工程证明单状态集中化能准确预测武汉实际建筑室温。

内部显热固定200W来自原件，原60%辐射/40%对流在1R1C中合并。太阳得热路径本次明确关闭，原始太阳气象列仍保留，`solar_gain_kw=0`是模型排除项，绝不是观测到全天无日照。潜热、生活热水、占用变化、热桥、地源和动态通风均不作效果声明。

```text
稳态实际供热=max(H*(20-Tout)-0.200,0)
稳态实际供冷=max(H*(Tout-27)+0.200,0)
稳态代数室温=clip(Tout+0.200/H,20,27)
容量参照=H*max(20-Tout,0)  # 无得热，RC中仅作容量/报告尺度，不再加一道固定服务
```

RC使用内核精确离散一阶方程，初温20℃、末温20℃，不在代表日重置；初始预热能量在比较窗口之外。初末状态是明示服务边界，不称室内观测。所有小时舒适20–27℃；整季最高外温加内部得热会触发少量供冷，因此按原理想系统1000kW/100%效率同时提供显热供冷，EER的上下界也显式设为1，避免软件默认下界1.5改变原件效率。

原理想系统在软件里通过 `electric_boiler` 热输出适配并接同源供冷，名称不表示实际电锅炉可制冷。共享1000kW上限加RC互斥服务；无实际压缩机资产或可投资容量。服务温级取上限27℃，只表示理想电加热零温差交付标签，**不是公布的厂家出水温度**；本案不得用该标签宣称完整系统㶲效率或真实供水温位收益。

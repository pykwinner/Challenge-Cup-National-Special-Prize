# 城镇供热源荷匹配项目已完成成果与创新特色总结

本总结按赛事七项官方评分标准，梳理项目已经完成的模型、算法、数据验证和实验成果，供后续论文、项目介绍和答辩取用。事实依据为2026年10月2日已发布的 **11.12.0rc5研究候选版**及其保留的历史实验。各项分值表示官方评分上限，不表示项目已经获得的分数。

项目的核心贡献是：**把建筑舒适需求、热源温位、共享资源、网络连接和设备运行放入可计算、可检验的供热决策框架，并用连续时序、对照实验和独立复算说明方案为何可行、为何产生费用与碳排取舍。**

这里的“创新”指本项目已经实现的方法改进、约束组织和集成贡献。MILP、1R1C、Wasserstein距离和ε约束等成熟理论保留其原有方法身份；本总结不作未经查新证明的“首次提出”或“国际领先”声明。

## 模型架构构建 满分20分

**已完成内容。** 项目建立了统一的源网荷储混合整数规划内核，将热源出力、温位准入、节点热平衡、设备及管网容量、储能状态、建筑冷热交付、投资运行费用和碳排放统一组织。建筑端由室温状态和舒适要求决定服务，空间端保留建筑、节点、片区及系统之间的归属关系。

原有框架进一步实现了共享余热资源上限、保障组合额度、燃料及电池事件初末状态、日历月需量或容量电费、冷热共用电表费用分摊。特别是余热直供与热泵取热共同消耗同一上游资源，能够防止分别计算设备能力时重复占用余热。

**方法特色。** 源荷匹配同时考虑“需要多少热、什么时候需要、通过哪条路径交付、热量的温位是否满足需求”。这些条件直接影响可行解及费用核算，使低温资源利用、建筑服务和系统容量可以在同一框架中比较。

新增的温度水力模块将供回水两腿热损、泵耗及温差偏离惩罚接入优化，并对不满足末端温度、回水、流速或压降等边界的模式自动反馈重求解。在72小时机制案例中，第三轮得到合格模式，最高活跃沿程压降由 **1081.42降至237.96 Pa/m**，满足设定的300 Pa/m上限，最低末端供水约57.45℃。相应参考电量费由178.64升至224.26元，量化了获得工程可行性所需的代价。

**可用于介绍的表述：** 本项目实现了建筑服务、热源温位与共享资源联立的供热优化框架，并在独立泵星状支路的有限稳态模式范围内实现工程校核反馈。

证据：[物理与费用接口](implementation_20261002/physical_extensions.md)、[温度水力反馈及验收](implementation_20261002_followup/parallel_stage_03/network/README.md)。

## 动态仿真能力 满分15分

**已完成内容。** 建筑采用小时内输入保持条件下的精确离散1R1C模型，持续递推室温，检查舒适上下限、初末状态、设备容量及冷热互斥。固定投资回放保持服务要求，并对状态连续性和输出账本进行复核。

乌鲁木齐、固原和武汉均完成 **2880小时连续运行对照**。每城保留反馈温控基准、费用端点、碳端点和中点碳帽方案，共12行结果；这些是同一120日连续窗口，时区和边界已登记。新增七组异质双楼案例、24个条件投资方案及其中四组固定容量回放，也均覆盖2880小时。

**方法特色。** 规划或选策结果继续接受完整连续运行检验，建筑状态跨日传递。代表日用于统计和估计时，与完整时序运行分别记录，避免由孤立日状态重置形成虚假节省。

验证从保存的逐时出力重算热冷交付、电量、费用、碳排和温度。早期武汉分时参考10组导出结果的室温方程最大残差约 **4.62×10⁻¹⁴℃**，说明在该数学模型内状态与账本一致。这属于数值一致性证据，室温预测精度另由外部观测检验。

**可用于介绍的表述：** 项目形成了从逐时服务需求到方案连续回放、再到独立物理与账本核验的动态验证流程。

## 多目标协同与收敛性 满分15分

**已完成内容。** 项目实现费用与碳排两阶段端点、ε约束采样、非支配筛选、逐阶段状态和目标上下界记录，并将自由投资、受限基准、固定资产回放的求解范围分别标注。条件投资参考采用0、1、2台热泵的完整候选枚举与逐时线性规划，保留五点ε采样、重复方案、敏感性及固定容量回放。

**亮点一是给出可解释的费用碳折中。** 三城共同参考中，把费用端点相对低碳端点的额外碳排空间减半，仍保留 **80.9%至89.4%** 的最大参考电量费节省。结果同时保留电量及峰值增加，能够具体说明减碳约束对移峰省费的影响。三城收敛复核中的九个优化案例、15个求解阶段正常结束，求解质量按各阶段实际返回的状态、界和容差解释。

**亮点二是让代表日权重服从能量与分布约束。** 已实现固定真实代表日下的能量和总天数硬匹配、极端日权重下界以及最小一维W1目标。W1衡量代表数据与原数据的负荷分布差异；该目标转化为标准线性规划，并在返回后独立重算。

- 在预冻结的六栋新建筑BDG2确认中，同一选日集合上的归一W1中位数由软权重的 **12.3150%降至4.47753%**，能量达到数值级匹配。门槛采用由3/6增至4/6，两例原始峰值保留不合格的候选仍被拒绝，门槛保持不变。
- 在三城27条连续策略的开发对照中，硬能量加最小W1的汇总费用MAPE由频数权重的 **0.556911%降至0.140535%**，相对下降约74.77%。频数权重12组预算选择中9组合格，四种硬约束方法均为12组合格。
- 新价格与时窗联合权重获得略低的最大能量误差，但费用估计不优于硬W1，四种硬方法也没有表现出彼此不同的合格选择遗憾。项目据不同用途报告方法优劣。

**亮点三是把投资结果转化为条件阈值。** 在冻结研究性能和其他费用条件、重复窗口权重F=5下，整台采购价格切换阈值约为 **9346.48元**；包外改造和维护差额可以显式修正该阈值。它使“什么条件下选择热泵”成为可计算问题。F表示同一120日费用窗口的研究权重，设备性能与未取得的费用是声明研究轴，该阈值不作为现实报价或全寿命收益。

**可用于介绍的表述：** 项目把代表期统计误差、实际预算可行性和费用碳取舍联系起来，并通过求解范围和上下界记录，使投资与运行结果具有明确的解释依据。

证据：[硬能量W1方法与六栋确认](implementation_20261002/algorithm_hard_weights/README.md)、[三城六方法解释](implementation_20261002_followup/parallel_stage_03/algorithm/interpretation.json)、[条件投资交付](implementation_20261002_followup/parallel_stage_03/investment/HANDOFF.json)。

## 多尺度耦合特性 满分10分

**已完成内容。** 项目建立逐楼独立热状态与系统共享电网约束的联合求解，并完成独立建筑、无共享上限、共享上限、单楼固定温度和双楼固定温度等七组各2880小时实验。A为公开原型，B为明确声明的H和C设计变体。

**最有说服力的结果是共享约束确实改变了建筑行为。** 两栋建筑分别优化后叠加，在共同配电上限下有 **229小时越限**；联合优化后越限为零，**6.4796375 kW**的共同上限在 **530小时**达到约束边界。相对无共享上限方案，A、B的供热安排分别改变418、1111小时，体现系统上限对逐楼调度的反馈。

在同一共享上限下，保留建筑温度调节自由度的参考电量费为5660.96元，双楼固定20℃策略为6033.45元，下降 **6.1737%**；电量及固定排放因子计算的碳排增加 **5.4323%**。固定20℃是同一20至27℃服务范围内更严格的控制方式，此对照用于量化柔性价值与代价。

**方法特色。** 楼宇热状态和系统容量不再只在汇总图上关联，而是通过实际生效的约束相互影响。当前实验已经验证调度层双向联动，系统投资响应与接入距离变化属于后续扩展。

**可用于介绍的表述：** 本项目以真实绑定的共享容量和逐楼状态响应证明多尺度耦合，使区域约束能够直接改变建筑运行安排。

## 建议主打的四项创新特色

1. **面向建筑服务与热源品质的协同建模。** 将逐楼舒适、热源温位、共享资源和费用碳账本联立，处理“热量够但温位不合适”“单设备可行但共同资源不足”等实际建模问题。这属于针对供热任务的集成贡献。
2. **能量硬匹配下的代表日W1权重优化及决策检验。** 将能量、天数和极端权重作为约束，优化负荷分布距离，再检验完整策略的费用估计与实际预算可行性。六栋新建筑确认和三城开发对照分别提供统计与选策证据。
3. **明确适用域内的温度水力校核反馈。** 将热损、泵耗、温差目标和硬工程边界联合处理，通过有效的有限模式剔除驱动重新优化，形成可保存、可复核的修复过程。
4. **以约束实际生效证明楼宇系统双向耦合。** 通过异质建筑连续消融、共享上限绑定时数和逐楼响应，量化建筑柔性、区域电力上限、费用与碳排之间的联系。

这四项以模型和算法为主，连续运行、真实外部数据、独立复算和版本化交付共同构成支撑证据。

## 可直接用于项目介绍的概述

本项目面向城镇供热中建筑需求、热源温位与资源空间分布之间的匹配问题，构建了集建筑动态热状态、源网荷储协同决策和费用碳评价于一体的规划与运行框架。项目实现能量约束下的代表日权重优化、有限模式温度水力反馈，以及共享资源约束下的异质建筑联合调度。通过三城连续气候对照、外部真实计量检验、多尺度消融和条件投资实验，形成了能够解释费用、碳排、功率峰值及设备选择条件的结果体系，并以独立复算和实际发布环境验证保障研究结果可追溯、可检查。

## 取用这些成果时保留的口径

三城对照使用公开BESTEST派生原型、NASA格点气象和共同方法学价格；相应费用是参考模型账本。条件投资中的真实历史报价与性能、费用研究轴分别登记。网络反馈适用于独立泵星状支路的有限稳态模式，当前多尺度案例验证调度层耦合。

本项目已经完成上述研究实现与参考实验。具体设备真实性能准入、同对象工程费用与账户、当地现场效果及企业鉴定仍需相应外部证据。新增5066行热泵资料属于参数储备，尚未接入当前结果，不计作已验证的模型改进。论文PDF、PPT和成员合作记录继续按后续真实材料整理。

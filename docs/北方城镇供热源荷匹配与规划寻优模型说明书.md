# 面向北方严寒地区的城镇供热源荷匹配与规划寻优模型说明书

## 摘要

本方案面向北方严寒与寒冷地区城镇供热需求，针对供暖季长、极端低温频发、负荷峰谷差大、传统系统“以煤保供”、低品位余热难以充分利用、热泵低温性能衰减以及管网改造投资高等问题，提出“温位—时间—空间—风险”四维协同的源—网—荷—储联合规划模型。模型以混合整数线性规划为核心，将工业余热、集中式与分布式热泵、调峰锅炉、双向供热管网、短周期储热、跨季节储热、建筑热惯性和需求响应纳入统一框架，同时显式考虑空气源热泵在低温下的COP下降、容量衰减与停机温度，管网热损随环境温度增大，设备启停与爬坡，系统备用容量以及复合寒潮风险。

相较于仅按峰值热负荷定容或只追求最低运行费用的方法，本方案能够回答“热从哪里来、以什么温度来、通过哪条管道送、何时储放、寒潮下如何保供、为进一步减碳需要增加多少成本”等关键问题。模型采用epsilon-constraint生成成本—碳排Pareto前沿，并通过膝点与边际减排成本推荐兼顾企业可承受性和低碳目标的方案。示例算例表明，在冻结既有投资的复合寒潮压力测试中，室外温度下降8℃、热负荷增加15%、工业余热可用率下降15%时仍可实现零失供，体现出“常态低碳、极端保供”的北方适用优势。

## 1 选题定位与北方问题特征

### 1.1 选题定位

本项目服务于CP-202611“面向供热格局变革的城镇供热源荷匹配与规划寻优模型构建”。研究对象不是单一热泵、单座热源厂或单条管线，而是城市尺度的供热资源配置问题：在既有管网与建筑条件下，确定不同热源、储热、管径和区域供热方式的投资组合，并给出可执行的逐时调度策略。

### 1.2 北方供热的六个特殊矛盾

1. **负荷大且刚性强。** 供暖不是一般可中断负荷，寒潮期间失供会直接影响民生和管网安全。
2. **峰值短、容量贵。** 极端低温负荷可能只持续几十小时，却决定热源和管径投资。
3. **热泵“越冷越弱”。** 室外温度降低时，空气源热泵COP和可用容量同时下降，恰与热负荷上升方向相反。
4. **热损与泵耗不可忽略。** 北方大温差、长距离输送使管网损失和循环泵耗随寒冷程度上升。
5. **余热资源存在时空错配。** 工业余热温度、位置、生产节奏与居民供暖需求不一致，需要热泵、管网和储热共同解决。
6. **低碳与保供存在张力。** 常态工况可由余热和热泵承担，极端工况仍需可靠调峰热源，不能用“全年平均低碳”掩盖寒潮风险。

因此，北方方案必须同时优化经济性、低碳性、温位合理性与供热韧性。

## 2 总体技术路线

模型采用“规划—调度—校正”三层架构：

- **规划层：** 决定热源扩容、储热容量、候选管线、管径和供热组织方式；
- **运行层：** 在典型日、设计日和不确定场景下决定逐时热源出力、管网流量、储热充放及需求响应；
- **在线校正层：** 利用负荷预测与MPC滚动修正热源、泵和阀门设定值。

规划模型采用MILP，便于保证可解释性、求解稳定性和结果复现。负荷预测与数字孪生用于增强运行效果，不替代能量守恒和工程约束。

## 3 基本集合、参数与变量

### 3.1 集合

- 节点集合 N：热源厂、热力站、小区或建筑群；
- 管道集合 E：既有管道与候选管道；
- 热源集合 S：工业余热、CHP、热泵、锅炉、太阳能等；
- 温位集合 G：高温散热器负荷与低温地暖/风机盘管负荷；
- 储热集合 K：水罐、PCM、BTES等；
- 时段集合 T：逐小时或典型时段；
- 不确定场景集合 Ω：常态、寒潮、余热低谷、电价高位等。

### 3.2 主要投资变量

- Xs：热源新增容量；
- Yed：候选管道e是否选择管径d；
- Vk：储热新增容量；
- Ze,t：双向管道在时段t的输送方向。

### 3.3 主要运行变量

- Qs,g,t：热源s向温位g的供热量；
- Fe,g,t+、Fe,g,t−：管道正向与反向热流；
- Qk,tch、Qk,tdis、SOCk,t：储热充放功率和状态；
- Qn,g,tup、Qn,g,tdown：需求响应上调与下调量；
- Bn,g,t：建筑热惯性虚拟储热状态；
- Un,g,t：供热缺额；
- us,t、vs,t：热源启停与启动变量。

## 4 目标函数与多目标决策

### 4.1 年化总成本

基础目标函数为：

min Ctotal = Cann + Cop + pc·ECO2 + λex·Dex + λu·Qunserved + λc·Ccomfort

其中，Cann为年化投资，Cop为燃料、电力、维护和泵耗，pc为碳价，Dex为温位不匹配造成的火用损失，Qunserved为失供量，Ccomfort为需求响应和室温偏差成本。

资本回收系数为：

CRF = r(1+r)^n / [(1+r)^n − 1]

### 4.2 成本—碳排Pareto前沿

单一加权和容易受主观权重影响。本方案使用epsilon-constraint：

min Cann + Cop + λex·Dex + λu·Qunserved + λc·Ccomfort

s.t. ECO2 ≤ εk

依次收紧εk得到非支配方案，并计算相邻方案的边际减排成本：

MACk = (Ck+1 − Ck) / (Ek − Ek+1)

最终对成本和排放归一化，选取距离双理想点最近的膝点作为推荐方案。

## 5 北方专属物理模型

### 5.1 温位匹配与火用损失

热量不仅有数量，也有温度品质。环境温度T0下，温度T对应的单位热量火用系数为；式中温度必须使用开尔文，不能直接代入摄氏温度：

e(T) = 1 − T0/T

热源s向温位g供热产生的火用损失近似为：

Dex,s,g,t = Qs,g,t·max[e(Ts) − e(Tg), 0]

温度不足的热源禁止供应高温负荷；高温热源可以供应低温负荷，但需要承担火用损失成本。由此促使工业高温余热优先服务散热器负荷，热泵和低温余热优先服务地暖负荷，减少“高能低用”。

### 5.2 空气源热泵低温性能

热泵COP采用温度相关Carnot修正模型，供水温度与热源温度均先换算为开尔文：

COPs,g,t = ηCarnot·Tsup,g,K/(Tsup,g,K − Tsource,s,t,K)

实际MILP不把COP作为决策变量，也不在约束中保留“供热量/COP”的非线性形式，而是根据气象场景和温位预先计算逆COP系数κ=1/COP，使热泵电功率写成Pel=Σκ·Q。

同时引入三类北方约束：

- 当室外温度低于阈值后，可用容量按温降线性衰减并设置最低容量系数；
- 在结霜温区对COP乘以除霜折减系数；
- 当温度低于设备停机温度时，可用容量置零。

因此模型不会在−25℃或更低温度下仍按铭牌COP和额定容量计算，避免系统性低估备用需求。

### 5.3 设备启停与爬坡

对锅炉、CHP等可控热源设置：

us,t·Psmin ≤ Σg Qs,g,t ≤ us,t·Psmax

并考虑启动、停机、最小出力和上下爬坡约束，使模型给出的调度曲线具有可执行性。

### 5.4 管网双向流动、低温热损与泵耗

候选环网允许双向运行，但同一时段不得同时双向输热：

0 ≤ Fe,t+ ≤ MZe,t

0 ≤ Fe,t− ≤ M(1−Ze,t)

管道输送效率不是固定常数，而是随室外温度降低而下降：

ηe,t = max[ηemin, ηe,0 − ke·max(Tref − Tout,t, 0)]

循环泵耗按输送热量的比例计入购电费用和电网间接碳排。

### 5.5 储热与跨季节边界

储热状态方程为：

SOCk,t = (1−ρk)SOCk,t−1 + ηkchQk,tch − Qk,tdis/ηkdis

短周期水罐和PCM使用日内循环边界；BTES等跨季节储热使用固定初始状态和期末最低状态，避免每个典型日首末SOC强制相等造成“季节储热失效”。正式全年模型采用月份锚点或典型日状态转移矩阵连接夏季蓄热与冬季放热。

### 5.6 建筑热惯性与舒适度

建筑围护结构的蓄热能力被建模为虚拟储热：

Bn,g,t = (1−ρB)Bn,g,t−1 + Qn,g,tup − Qn,g,tdown

其上下界由建筑等效热容和最大允许室温偏差决定。需求响应必须在4～6小时窗口内能量守恒，并对室温偏差累计值设置舒适性成本，避免把早高峰负荷无限转移到深夜。

### 5.7 备用容量与供热可靠性

北方系统设置系统级可靠容量约束：

Σs κs·Psfirm ≥ (1+R)·Dpeak

其中κs为可靠容量信用，空气源热泵按照寒潮最差可用率折算，工业余热考虑停产和波动，燃气/燃煤调峰热源给予较高容量信用。R为备用率。

失供不仅进入目标函数，还设置硬约束：

Σn,g,t Un,g,t / Σn,g,t Dn,g,t ≤ εreliability

从而避免模型为了减碳或省钱主动牺牲居民供暖。

## 6 节点热平衡与容量约束

每个节点、温位、时段满足：

Σs Qs,g,t + Σein ηe,tFe,g,t + Qdis + Unserved

= Dn,g,t + Qup − Qdown + Σeout Fe,g,t + Qch

候选管道每条边最多选择一种管径：

Σd Yed ≤ 1

Σg(Fe,g,t+ + Fe,g,t−) ≤ Ceexist + Σd CedYed

这些约束把热源、储热、管网和负荷连成物理闭环，确保每一单位热量都有来源和去向。

## 7 不确定性与复合寒潮测试

### 7.1 不确定参数

重点考虑室外温度、热负荷、工业余热可用率、分时电价和电网碳因子。规划变量在所有场景共享，运行变量允许随场景调整。

### 7.2 两阶段鲁棒模型

完整形式中，热源、储热与管网投资变量在所有场景共享，运行变量允许随场景调整：

minx cTx + maxu∈U miny bTy

预算不确定集通过Γ控制同时发生不利偏差的数量。Γ越大，投资越保守、寒潮风险越低。对有限寒潮与故障场景，优先构建共享投资变量的确定性等价MILP；大规模连续不确定集再采用列与约束生成算法C&CG。尾部运行风险可通过CVaR的线性辅助变量ζ和ξω计入目标。

### 7.3 冻结投资压力测试

为避免压力测试中“临时新建设备”，先求常态最优投资，再冻结热源容量、储热容量和管网方案，只允许重新调度。复合寒潮同时设置：

- 室外温度下降8℃；
- 热负荷增加15%；
- 工业余热可用率下降15%。

示例结果仍保持零失供，但备用热源介入，清洁热占比由100%降至约78.9%，年化运行相关成本和碳排明显上升。这一结果说明模型不会用不现实的“全清洁能源满发”掩盖寒潮保供，而是准确呈现安全保障的经济与碳代价。

## 8 算法与求解流程

1. 清洗气象、负荷、热源和GIS数据并统一单位；
2. 按月度和日负荷特征构建保序典型日，并额外加入极端设计日；
3. 建立确定性MILP基线并完成物理守恒测试；
4. 使用epsilon-constraint生成成本—碳排Pareto前沿；
5. 加入寒潮与资源波动场景，采用场景枚举或C&CG求解；
6. 对推荐方案执行冻结投资压力测试；
7. 通过消融实验验证温位、储热、需求响应和鲁棒约束的贡献；
8. 将规划结果接入负荷预测和MPC形成数字孪生闭环。

## 9 示例结果与解释

当前示例为合成小算例，仅用于验证模型逻辑，不代表正式赛题结论。北方增强模型在常态场景得到：

- 年化综合成本约79.51万元；
- 年碳排约310.58吨；
- 供热缺额率为0；
- 火用效率约82.51%；
- 新增工业余热回收能力450kW；
- 新增集中式余热源热泵约211kW；
- 新增低温水储热约1235kWh；
- 建设DN150直连支路，形成更适合寒冷条件的输热路径。

Pareto前沿显示，推荐膝点约为年排放300.20吨、年化成本80.54万元；继续压低至298.13吨时，边际减排成本上升到约36.67元/kgCO2，说明已进入高成本深度减排区。

消融实验表明，取消新增储热后年化成本升至约83.24万元，证明储热对削峰和降低热源容量具有明显作用；取消需求响应后成本和碳排小幅上升；取消火用损失惩罚虽然账面成本下降，但会削弱温位合理性，不能据此认定方案更优。

## 10 方案的核心优势

### 优势一：真正面向北方，而非普通综合能源模型换数据

模型显式描述低温热泵衰减、除霜、停机温度、寒冷管损、泵耗、备用率和复合寒潮，北方特征进入约束而不是停留在文字背景。

### 优势二：同时优化热量和热能品质

通过温位兼容矩阵和火用损失定价，避免高温热源供应低温末端造成品质浪费，能够解释为什么同样满足热负荷，某一方案更节能。

### 优势三：规划、管网和运行联合寻优

传统方法常先定容量、再画管网、最后调度。本方案同时决定热源容量、储热、管径、路径和逐时运行，减少分步优化造成的次优解。

### 优势四：兼顾常态低碳与极端保供

平时优先余热和热泵，寒潮时由可靠备用热源兜底；用冻结投资压力测试证明方案在不新增设备的情况下仍可供热。

### 优势五：建筑热惯性成为可量化资源

将建筑围护结构等效为虚拟储热，并受室温边界和恢复损失约束，既能削峰，又不会牺牲居民舒适度。

### 优势六：多目标结果可解释、可决策

不依赖主观权重给出单一“最优值”，而是展示Pareto前沿、膝点和边际减排成本，便于企业根据资金与碳目标选择方案。

### 优势七：模型严谨且代码可复现

主模型保持MILP，可由HiGHS免费求解，也可切换Gurobi或CPLEX；参数集中在YAML/CSV，便于迁移到不同北方城市。

### 优势八：具备数字孪生落地接口

规划结果可作为数字孪生的设备和网络边界，负荷预测与MPC负责日内滚动修正，形成“规划—预测—控制—反馈”闭环。

## 11 与常见方案的对比

| 对比维度 | 常见方案 | 本方案 |
|---|---|---|
| 热负荷 | 单一热量平衡 | 高低温位分级并计算火用损失 |
| 热泵 | 固定COP和额定容量 | COP、容量、除霜和停机温度均随低温变化 |
| 管网 | 固定拓扑或单向流 | 拓扑、管径、双向流、寒冷热损和泵耗联合优化 |
| 储热 | 简单日循环SOC | 短周期循环与跨季节固定边界并存 |
| 需求响应 | 任意平移负荷 | 响应窗口、建筑热惯性和舒适成本共同约束 |
| 可靠性 | 只设置缺额罚值 | 备用容量、硬失供率和复合寒潮压力测试 |
| 多目标 | 主观加权和 | epsilon-constraint、膝点和边际减排成本 |
| 工程落地 | 结果难迁移 | 参数化数据接口、自动测试和可视化输出 |

## 12 评价指标体系

经济指标包括年化总成本、单位供热成本、投资回收期和边际减排成本；低碳指标包括年碳排、清洁热占比、余热利用率和峰值电功率；热力学指标包括一次能源利用率、火用效率和温位匹配率；安全指标包括失供率、备用率、寒潮供热缺额和最大设备负载率；舒适指标包括室温偏差小时数和需求响应回弹量；计算指标包括求解时间、MIP gap和场景收敛次数。

## 13 数据需求与参数校准

正式建模需要热力站/小区坐标、建筑面积、末端类型、逐时负荷、室外气象、热源位置与温度、设备成本与效率、管线长度和管径、分时电价、电网碳因子以及余热生产节奏。空气源热泵COP和容量曲线应优先采用厂家样本或实测数据进行分段线性拟合；管损参数应结合管径、保温和供回水温度校准；建筑热容可通过室温响应数据辨识。

## 14 局限性与后续升级

当前基线将水力压降和温降简化为线性参数，正式高精度版本可增加质量流量、供回水温度和泵特性分段线性化；跨季节BTES需使用全年或保序典型日数据，不能仅凭24小时示例确定容量；鲁棒规划目前提供场景生成和压力测试接口，后续应实现投资共享的完整C&CG；真实项目还需加入土地、道路开挖、热源停产检修和燃气供应约束。

## 15 结论

本方案以北方城镇供热的严寒、刚性和安全属性为出发点，将温位匹配、低温热泵、双向管网、建筑热惯性、短期与季节储热、备用容量和复合寒潮纳入统一规划模型。其最大价值不是单纯降低某个成本数字，而是建立一套可解释、可验证、可迁移的决策工具：常态工况最大化利用余热和清洁电力，极端工况确保居民供热安全，并清晰量化低碳、经济与可靠性之间的权衡。

完整的集合、变量、两阶段目标、CVaR、N-1、储热持续时间可靠容量、线性化方法和求解顺序见《北方供热优化数学模型与公式附录》。

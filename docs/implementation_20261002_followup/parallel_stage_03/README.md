# 第三轮：把模型特色补成可运行、可核验的实验

本轮沿用原工程，保留 rc4 及此前冻结证据。PPT、论文 PDF 未制作。这里登记方法和实验的实际覆盖范围，不预测赛事得分，也不把参考实验升格为三城现场工程验收。

## 已形成的主要特色

### 建筑与系统真正双向耦合

[多尺度完整报告](multiscale/run_01/analysis/RESULTS.md)覆盖七组各 2880 小时的连续案例。A 为公开 BESTEST 派生原型，B 为明确声明的 H×1.5、C×4 设计变体；两者采用相同 20—27℃服务范围和初末 20℃。

分别优化两栋建筑再叠加，在共同配电条件下有 229 小时越限；联合优化后，6.4796375 kW 的上限真实绑定 530 小时，越限为零。共享约束分别改变 A、B 的供热安排 418、1111 小时，说明系统约束确实传递到建筑状态。

相同共享配电条件下，利用建筑柔性的参考电量费为 5660.964848 元，全部固定 20℃的操作策略为 6033.452112 元，下降 **6.1737%**。同时，电量和固定排放因子计算的碳排增加 **5.4323%**，这一代价必须一起展示。无共享上限的方案虽然更便宜，但不能作为相同配电条件下的可实施基准。

全部关闭柔性的消融均可行，没有把“费用更高”写成“无解”。两个建筑同时改变 H/C，因此不能将 B 的差异单独归因于热容量。完整表格、逐楼变化和三组 PNG/SVG 图均由保存的逐时结果生成。

### 工程校核能反馈到优化器

[温度—水力闭环](network/README.md)增加了独立星状支路有限稳态模式：供、回水两腿热损与泵耗进入主模型，温差目标偏离单独计惩罚，末端温度、回水、流速、压降和瞬时容量保留硬边界。

72 小时的机制实验先选出违反压降上限的低费用档位，自动剔除后重新求解，第三次得到合格模式。最高活跃沿程压降由 1081.42 降到 237.96 Pa/m，满足明确设定的 300 Pa/m 上限；最低末端供水约 57.45℃。参考电量费由 178.64 升至 224.26 元，说明闭环修复的是工程可行性，不能宣传成省费。

温差惩罚 0.2 的当前对照没有改变最终调度，保留负结果。有限模式的有效性由守恒、独立摩擦求根、穷举最优目标和反例测试验证。方法明确不涵盖网状共泵、运输延迟、冷启动或间歇供热的 RC 室温认证。

### 投资规划从单点结论推进到条件采购阈值

[投资交付索引](investment/HANDOFF.json)与[运行说明](investment/RUNBOOK.txt)覆盖同服务基准、最低比较费用、最低参考碳排、折中方案、五点ε采样、敏感性及四组固定资产连续回放。正式引用修正后的 `investment/run_03`，旧两轮及第一次复算均保留。该实现通过整数台数完整枚举结合逐时RC线性规划，保留各候选的主/次阶段状态与相应下界。

采购合同中的 FT-FDRS-8/380FWAW 名义8kW和历史含税成套价17800元属于真实来源量，按整台计价。未知的实际COP曲线、可用率、末端与备机费用、维护和运行窗口权重属于明确的研究条件，逐字段分开登记；不能据此说已经取得FT8真实性能准入。

在本轮冻结的研究条件、重复窗口权重 F=5 下，最低比较费用选择零台热泵和有限有价电阻设备；最低碳排、折中方案选择一台热泵。比较费用为一次购置费加 F 倍同一120日参考电量费及维护预算，没有伪造五个年度气象或真实寿命、折现、回收期。

保持研究性能和其他费用不变，0/1/2台候选的费用下包络给出整台价格切换阈值约 **9346.48元**：低于阈值选择一台，高于阈值选择零台，两台在非负价格范围内被支配。这是给采购决策使用的条件阈值，不是设备真实报价范围。新增户内或配电改造差额会改变阈值，相关变换另外列出。

中间ε档位出现相同方案，完整保留，没有伪造五个不同前沿点。基准只在零台热泵域内优化，固定容量回放只在实际固定投资域内优化，各自下界不能冒充原自由投资问题的下界。任何候选主阶段成功、次阶段失败都会使完整枚举声明失败，同时保存已得主阶段界。

新数值输入包默认不含原合同PDF，继承已登记的来源审核身份；严格原件模式在缺原件时先停止并输出链接和SHA，避免把无PDF复算写成重新读取了原合同。

### 代表日权重以实际策略决策检验

[三城正式开发对照](algorithm/confirmation_run_01/summary.json)固定每城8个实际代表日、九条温控策略及四档预算，比较六种权重。三城27条策略各沿完整2880小时连续运行，合计77760个策略小时；没有每天重置状态，也没有以此证明节省完整仿真时间。

| 方法 | 全27策略费用MAPE | 最大能量APE | 12组中实际合格选择 | 其他结果 |
|---|---:|---:|---:|---|
| 频数权重 | 0.556911% | 0.718644% | 9 | 2组实际超帽，1组无选择 |
| 软能量校准 | 0.448316% | 0.291601% | 11 | 1组无选择 |
| 硬能量＋最小W1 | **0.140535%** | 0.315063% | 12 | 相对频数费用MAPE下降74.77% |
| 硬能量＋最小L1 | 0.460634% | 0.289511% | 12 | 用于区分目标与价格约束效果 |
| 价格与时窗联合矩＋L1 | 0.485844% | **0.289022%** | 12 | 最大能量误差略低，费用精度低于硬W1 |
| 候选L1位移上限内的W1 | 0.329306% | 0.290410% | 12 | 另计依赖候选校准的计算成本 |

四种硬约束方法的合格选择都与本九策略库的全时序最优选择一致，遗憾为零，因此没有证明新候选优于其他硬方法的选策能力，更没有证明全局控制或投资更优。软能量校准不是“软W1”。价格候选约束同时包含价格和两个时窗矩，不能把差异单独归因于价格。

冻结的开发推荐规则先比较合格选择与遗憾，再比较最大能量误差，故返回价格联合候选；其对最小L1控制的最大误差改善只有约0.000489个百分点。对费用估计用途，当前硬W1证据更强。保留两者及用途边界，不为宣传新算法改写预先登记规则或盲目替换主流程。三城输入属于已见开发数据，本轮不称新鲜留出验证。

## 数据真实性与研究条件

| 类别 | 本项目的处理 |
|---|---|
| 原始公开资料 | 保留发布主体、网址、原件身份及字段定位；气象为公开格点产品，不能标为现场气象站实测 |
| 来源可核算的派生量 | 保存原型几何/材料到 H/C、时区转换、电价对应及负荷计算规则 |
| 设计与研究变量 | 管网几何/运行模式、B建筑H/C变化、未知设备性能和费用情景显式标注；不写成实测数据或某型号真实区间 |
| 求解输出 | 明确为参考模型计算结果，保留解的约束范围、求解容差和失败记录 |
| 真实工程效果 | 需要对应对象和适用参数的工程依据；本轮没有补造计量数据、企业鉴定或现场节省 |

因此，研发实现完成与设备工程资料准入是两个不同状态。确切型号性能、户内末端/配电费用和适用账户尚不充分时，给出有条件的选择和阈值，不以零成本、免费无限备机或跨型号COP代替缺失依据。

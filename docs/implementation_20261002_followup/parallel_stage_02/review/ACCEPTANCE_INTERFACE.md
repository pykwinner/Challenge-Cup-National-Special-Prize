# 价格配对权重候选：实施前验收接口

2026-10-02；独立方法审查第一阶段。本文件仅提出实施与实验准入接口，未运行下一确认集，未改模型/旧证据。本阶段内部SCADA不是前置条件。已读最新`THREE_CITY_DECISIONS.md`：武汉2880h、8策略样本现在是开发样本；三种方法均选择δ=0，尚无选策优势；硬权重费用MAPE最低，能量MAPE仍由软权重最低。

## 先锁定问题

只在相同真实代表日上改变权重。价格配对矩约束LP是标准LP及工程特征选择，不称新理论算法。参考热负荷q不是策略耗电，p·q的配对矩也不是实际策略电费；没有覆盖其动力学/转换误差时不得给精确费用保证。

建议统一日矩接口：`phi_j(d)=sum_h f_j(q[d,h],p[d,h],segment[d,h])*dt`；同一完整窗口目标`b_j=sum_d phi_j(d)`；权重要求`sum_k w_k=D,w_k>=l_k,abs(sum_k w_k*phi_j(k)-b_j)<=tau_j`。基础特征可采用总参考能量、价格×参考负荷及预声明价格时段参考能量，明确每一项单位。时段来自已准入账户规则和本地时钟，不由排序后的价格/负荷独立拼配。

## 输入及输出合同

- 输入必须包含完整连续窗口、真实日期到代表日的唯一映射、全量及代表日参考负荷/价格/时段、原频数、共同下界、dt与特征定义；长度、日期、行序、有限值、单位和适用账户先检查。所有方法共用同一选择及下界；不得为了矩可行性重新选日。
- 候选只能用事前声明的外生参考/价格/时段特征校准，不使用完整策略库的实际电费、耗电、最优策略标签或确认结果作为目标矩。若另做oracle-moment实验，必须独立命名，不能算可部署候选。
- 输出明确`ok / infeasible / zero_reference_undefined / solver_failure / time_limit`及原因；未通过残差复核不得返回可采用权重。不能将失败自动退回旧权重后记为候选成功。
- 每个矩须保存名称、公式、单位、原目标、估计值、原单位有符号/绝对残差、相对或零目标残差规则、容差、是否通过；还需保存总天数、下界残差、W1、完整目标复算、求解状态/时间与输入/代码hash。
- 硬等式增加后目标可能位于固定日支持的凸包之外；应报告不可行，不偷偷放松矩。常数价格、恒定时段、重复或线性相关特征需说明冗余及正常退化处理；零负荷不计算除以均值的归一W1。
- 权重退化最优解的平局规则在确认前固定。不得根据哪组下游指标更好挑一个LP最优解；若二级靠近原频数等规则改变结果，登记第二阶段和完整耗时。

## 必要的解析检查（不使用确认集）

1. **配对反例：** 两小时价格[1,10]、负荷[1,3]与[3,1]。两组能量均4、负荷标量W1=0，费用分别31与13。证明独立边际/能量不保持价格配对；不可在生产数据中置换时间。
2. **可行/不可行：** 手工小矩阵可独立求得权重；目标在固定支持外、下界和超过总天数时应明确不可行；矩约束不应以失败回退擦除。
3. **原尺度残差：** 同时测很小/很大目标、零目标、不同价单位及dt；缩放只用于数值求解，返回指标须回到原单位。
4. **日期及价格配对：** 代表日取同一天的所有列；乱序/重复/缺小时、跨时区/月价边界、映射错位须拒绝或显式规范化并留审计。
5. **退化与失败：** 常量序列、冗余矩、空价段、非有限数、预算超限、求解器无最优权重及多最优平局均有明确状态。

## 进入比较前的闸门

冻结算法/特征/归一尺度/阈值/平局及运行预算后，父对话才能锁定未参与调参的新时间窗或对象。三城同时间窗同原型首先是气候机制比较，不自动成为三个独立站点或当地实测。B必须给出精确[start,end)、时区、逐时完整性、来源及初末状态，不能用“同为冬季”代替同一连续窗口。

频数、软能量、硬能量最小W1、新候选共用同一代表日期、普通/极端日下界、策略库、服务边界和预算；新候选多用计算须计入端到端时间。全量失败、实际超帽、无估计可行策略及不利指标保留。

保留“选策后按该策略连续回放”的评价路径。不得把各方法选择擦掉后，全部用完整季主模型重新优化，并将相同结果称权重改善。完整季主模型若作为另一个参照，独立命名及计时。

只有实际能量/碳帽、舒适、容量和初末状态均通过，才报告合格费用改进。固定碳因子时能量/碳帽等价，不计作两项独立成功；库内oracle只枚举预声明策略库，不称主模型全局最优。单个标量W1及硬参考能量均不等于多变量运行误差。

评分映射：S1检验参考量、转换与约束身份；S2检验连续状态和逐时服务；S4检验费用/能量/碳帽与有限库决策误差；S6保留配对与不利结果；S7输入校验、身份和失败可复现。上述为研究验收建议，不是官方新增分值或扣分规则。

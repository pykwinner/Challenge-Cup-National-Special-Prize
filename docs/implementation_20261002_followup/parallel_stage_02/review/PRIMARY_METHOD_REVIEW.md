### 1. 可实施的配对矩及边界

对实际日d，用已准入的参考功率q、同小时价格p及固定窗口掩码a定义

\[
E_d=\Delta t\sum_hq_{dh},\quad
B_d=\Delta t\sum_h p_{dh}q_{dh},\quad
U_{rd}=\Delta t\sum_h a_{rdh}q_{dh}.
\]

固定实际代表日S、权重下界l和总日数D，要求`1ᵀw=D,w≥l`，硬保持参考能量，价格/窗口矩采用事前声明误差带。总能量与标量负荷分布相同并不保持B：两小时p=[1,10]，q=[1,3]或[3,1]时，总能量均4、负荷W1=0，电费却为31或13。此反例为本审查的简单代数说明，不改真实数据的顺序。

如果q确为某固定策略的实际耗电，价格在每个分段r恒为p_r，保持各段实际电量就保持`C=Σ_r p_r E_r`。月份价格不同则分段必须包含月份/适用价表；只保留“峰平谷”标签不够。当前q是无得热参考热负荷，热泵转换、RC和控制会改变实际耗电，故`Σp·q`仅是配对代理。Merrick的内生价格结论提供动机，不给这一代理精确费用保证。

固定支持上的联合可行性为：设矩阵Φ列为各代表日特征、R=D−1ᵀl，则误差目标盒需与`Φl+R·conv{Φ的列}`相交。逐行区间都包含目标仅是必要条件，不保证共同权重存在；候选代码对此已正确注明。保留不可行例，不增加代表日、放松ε或换算法后仍报原候选成功。

### 2. 决策误差的可检验条件

有限冻结策略库P中，真实成本C(u)、估计成本Ĉ(u)。若对所有策略有`|Ĉ(u)−C(u)|≤η_C`，且真实预算内最优u*仍在估计可行候选中，则最低估计费用所选策略的实际费用差最多`2η_C`；预声明费用平局容差τ_C时再加τ_C。这是三项加减的直接代数界，不是本项目新定理。

预算会改变候选集合。若还确知所有策略`|Ê(u)−E(u)|≤η_E`，采用`Ê(u)+η_E≤B`才保证所选实际不超帽；真实最优若没有至少`2η_E`的预算余量，可能被这条安全筛选剔除，不能继续无条件套用`2η_C`相对原可行库最优的界。开发集最大误差、经验分位数或参考矩误差不是下一窗口确定性的η_E。当前候选没有这些统一运行误差保证，必须实际核验超帽、误选和库内regret。

费用均值改善不能覆盖预算失败；选中实际不可行策略时不报告“合格regret”或费用收益。固定碳因子下碳帽与能量帽等价，不计为两项独立成功。库内最优仅对冻结P成立，不能称主模型或全部温控策略全局最优。

### 3. 连续状态及评价路径

RC与储能满足`x(t+1)=A(t)x(t)+B(t)u(t)`。在代表期中处理长状态，至少需要原日到代表日映射f、周期间递推及重构状态界；常A可写`x(i,h)=A^h x_inter(i)+x_intra(f(i),h)`。只改权重不补这些联系。

当前有限策略诊断先沿真实连续季生成各策略轨迹，再按真实日切片，继承各自真实起始状态，并计最后恢复服务所需冷热能量。它是合法离线诊断，但已支付完整库仿真成本，不称减少仿真时间或预测样本外。下一窗口仍应保留同一状态/服务合同。

两种“连续评价”不可混用：

- **权重→有限策略选择：** 冻结选中的策略，运行该策略；若改为全季主模型自由重优化，就擦除了选策差异。
- **代表期→自由投资：** 冻结所选资产x，在同服务完整时序重新优化运行u，评价该资产的可行性及费用；资产选择保持不同，不在回放时重新投资。

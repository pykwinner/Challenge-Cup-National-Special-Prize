## 用户最值得提供的一份真实项目数据

**乌鲁木齐、固原或武汉任选一城，一个有数据的热站/楼栋/农宅即可。** 给已有原始CSV/Excel，附对象说明及可脱敏的型号、账单/合同；不必先改列名。

| 最小记录/说明 | 建议字段与单位 | 对应边界 |
|---|---|---|
| 对象与时间 | 项目/建筑/区域/设备/回路/表计ID；区间起止时间（ISO8601、`+08:00`）；原间隔min | 各表覆盖哪个对象；时间标签起点/终点；缺测、复位/换表、检修标记保留 |
| 入楼热输入，二选一 | 热表累计或区间量（kWh热或GJ）；**或**同步供回温（℃）、流量（m³/h）及介质 | 入楼、源出口、多栋汇总分开；有热表时温差/流量为建议补充，注明表计精度 |
| 同步温度与控制 | 室外/实测室温/设定温度（℃）；启停0/1、运行模式 | 室温传感器位置；近站外温来源/距离；已有除霜/辅热日志；设定值不代实测 |
| 实际能源分表 | 电量（kWh电）；或燃气（Nm³、标准状态）/燃料（kg，类型及已有热值/含水率） | 本体、辅机、全站共表分开；不强求两类能源同时存在；费用/效率核验用此项 |
| 静态底稿与适用性 | 采暖面积m²、层高m、围护层序/厚度、用途/服务时段、完整设备型号；合同/账单有效期 | 电表类别、结算电压、容量/需量；报价含安装/辅热/末端/维护的边界；未知留空 |

建议原始**10–15分钟、连续约14天或更长**；其他已有频率/时长也先交，**不是赛事门槛，不保证可辨识**。动态检验至少应含稳定运行、不同外温/负荷及自然启停/降档/冷却过渡段；只有恒定工况时热容辨识受限，无需额外改变运行。另留未参与拟合的变化段验证。**H/C可由构造推导初值/范围，不强求实测**；未知COP时电量不能当热输入，但可先核用电/启停。

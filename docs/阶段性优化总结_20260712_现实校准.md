## 一、本轮结论

本轮不是继续堆叠技术名词，而是用公开事实检查模型里最容易“算得过于乐观”的假设。完成后：

- 公开证据库由24个来源、84条事实扩展为**67个来源、312条结构化量化事实**；
- 固原场景纠正了低估的颗粒价格、无证据免费既有资产、20%生物质硬下限和低温热泵参数；
- 乌鲁木齐场景增加余热共同失效、应急资产保留和热源/骨干管N−1的可靠性叠加；
- 武汉场景首次以实际逐时冷负荷代理闭合“供暖—制冷共用热泵和配电资产”，并约束地源年吸放热平衡；
- 修复了原平准供热成本漏计生物质采购费的财务口径错误；
- 全部19项自动测试通过，新增7张PNG和7张SVG答辩图。

## 三、模型层面的核心修改

### 3.1 武汉：全年供暖—供冷联合容量

对可逆热泵 (s) 和时段 (t)，新增供冷出力 (Q^{cool}_{s,t})，并与供热共用装机：

\[
\sum_g Q^{heat}_{s,g,t}+Q^{cool}_{s,t}
\le a_{s,t}\left(K_s^{exist}+K_s^{new}-K_s^{retire}\right).
\]

节点供冷守恒为：

\[
\sum_{s\in S_n^{cool}}Q^{cool}_{s,t}+U^{cool}_{n,t}=D^{cool}_{n,t},
\]

并对总体和每个场景强制 (U^{cool}=0)。供冷耗电按逐时EER计入配电连接、运行费和碳排，不再用主观资本折扣代替夏季业务。

武汉公开气象代理生成约0.689 GWh原始年供冷需求；经过代表日与在室率口径后，联合求解的年供冷服务量约0.661 GWh。

### 3.2 武汉：地源热泵年吸放热平衡

地源冬季吸热与夏季释热分别为：

\[
E^{ext}=\sum_t Q^{heat}_{t}\left(1-\frac{1}{COP_t}\right)w_t,
\qquad
E^{rej}=\sum_t Q^{cool}_{t}\left(1+\frac{1}{EER_t}\right)w_t.
\]

每个随机场景均约束：

\[
0.80\le \frac{E^{ext}}{E^{rej}}\le1.25.
\]

本轮联合方案比值为0.930，落在约束区间内。

### 3.3 固原：证据覆盖配置

公开证据版执行以下修正：

- 成品颗粒到场价由约0.496元/kg修正为1.00元/kg，0.75和1.20元/kg作为敏感情景；
- 既有80 kW可再生电、40 kW/480 kWh电池和80 kW备用电源全部置零，候选投资仍可优化；
- 热泵截止温度由−24℃改为−25℃，−12℃COP约2.20、−20℃COP约1.93，并在−20℃以下保守降容；
- 基准取消没有公开依据的20%生物质硬下限；
- 新增宁夏居民清洁供暖电价列，16小时谷段0.2486元/kWh、8小时峰段0.4986元/kWh；同时保留一般总表代理情景，防止误用居民优惠电价。

农业秸秆与木质修剪/废木料必须拆成两条供应链，但在没有县域可签约量、含水率和逐月到货数据前，本轮没有虚构第二条链的资源上限。

### 3.4 修正现金口径平准供热成本

原指标只计年化投资、一般运行费和碳成本，遗漏单独记录的生物质采购费。现改为：

\[
LCOH^{cash}=\frac{C^{cap,reg}+C^{op}+C^{carbon}+C^{fixedOM}+C^{startup}+C^{biomass}}{E^{heat}}.
\]

舒适、火用失配和CVaR仍保留在系统优化目标中，但不混入现金热价；系统风险调整成本另行输出。

### 3.5 乌鲁木齐：可靠性叠加

现实可靠性覆盖配置执行：

- 工业余热及依赖同一工业过程的余热源热泵不计独立可靠容量；
- CHP和燃气应急锅炉在可靠性回放中不得退役；
- CHP、燃气热源和骨干管执行N−1；
- 储热可靠时长保守取12小时，覆盖公开8小时一般事故抢修目标。

70%共同工业限产、8小时故障时序、CHP每日6小时40%低负荷窗口和供热退费仍以元数据明确标记，尚未伪装成已实现的精细运行约束。

| 固原颗粒1.20元/kg | 0.357 | 0.400 | 78.0% | 0 |
| 固原证据基准+强制20%生物质 | 0.330 | 0.370 | 89.9% | 0 |
| 乌鲁木齐基础确定性规划 | 0.153 | 0.159 | 75.0% | 0 |
| 乌鲁木齐可靠性叠加 | 0.161 | 0.167 | 75.0% | 0 |

| 武汉供暖—供冷联合 | 供热监管口径0.483 | 0.352 | 99.9% | 热/冷均为0 |

关键解释：

1. **固原旧模型低估现实成本。** 证据校准后现金热价提高约35.0%，这是取消免费资产、纠正颗粒到场价和重算热价口径的合成结果。
2. **20%生物质硬下限是非绑定约束。** 取消和恢复该下限得到同一最优解，因此应将其移出基准政策，保留为情景扫描。
3. **可靠性有明确保费。** 乌鲁木齐可靠性叠加使现金热价提高约5.5%、年化投资提高约7.8%、配电接入提高约23.5%，但保持零失供。
4. **武汉全年共享是物理闭合后的真实价值。** 联合方案服务热量从约0.875 GWh扩展到热+冷约1.536 GWh，年化资本几乎不变，系统单位服务成本下降约27.1%。
5. **0.337元/kWh不是新的监管热价。** 它是按实际冷热服务量对共享资本做能量比例分摊后的供热结果；不应与仍承担全资本的0.483元/kWh监管口径混用。

## 六、必须诚实披露的剩余边界

1. 武汉冷负荷是“公开气象+温湿度自然通风门槛+在室日程”的透明代理，尚未用实测冷量或建筑仿真校准。
2. 武汉生活热水尚未进入联合优化，因此当前是“热—冷”而非完整“热—冷—DHW”。
3. 地源约束完成了年吸放热比，但尚未把10年地温状态作为规划变量；现有BTES模块可做独立长期筛查。
4. 乌鲁木齐仍把工业余热聚合为一条链，下一步应拆为新特、兖矿、新疆众和、国能化工四个来源并增加共同原因事件。
5. 代表日内储热不能替代真正的跨季节SOC；全年连续时序模块已经存在，但尚未与大规模代表日规划完全耦合。
6. 固原居民优惠电价只适用于符合政策条件的居民清洁供暖用电，区域微网或公共总表必须单独确认电价类别。
7. 固原生物质仍缺木质废料与农作物秸秆的县域可签约量、逐月到货、含水率、消防仓储和7—14天中断数据。
8. NASA POWER仍是原型气象底座；正式提交应使用CMA站点、多年典型年和实测负荷进行偏差订正。

## 七、下一阶段优先级

1. 将武汉生活热水、除湿和夏季配电峰值加入全年多服务模块；
2. 将乌鲁木齐四个工业余热源、共同限产和主干管8小时事故写入显式场景；
3. 建立月度状态转移或保序代表日，使PTES/BTES真正跨季节运行；
4. 获取固原木质废料/秸秆分链资源调查和供应商报价，替换聚合资源上限；
5. 增加用户账单、收入分位能源负担、财政补贴和补贴退出后的可负担性；
6. 用多年气象与实测冷热量做样本外回放，再生成成本—碳排—可靠性Pareto前沿。

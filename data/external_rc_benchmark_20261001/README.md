# 独立外部 RC 实测适用性验证

实际找到了并下载可复核数据：Kersken, Matthias; Strachan, Paul (2020), *Twin House Experiment IEA EBC Annex 71 Validation of Building Energy Simulation Tools - Specifications and dataset*, version 2, Fraunhofer IBP/Fordatis，[DOI 10.24406/fordatis/76.2](https://doi.org/10.24406/fordatis/76.2)。原机构页面及实验规范随本包缓存。选用德国Holzkirchen的N2电加热试验房；温度、房间电热输入和现场天气为发布者处理过的实验测量，完整主试验11988条连续10分钟记录（2018-12-07 18:10至2019-03-01 00:00，固定UTC+1）。

**验证结论：当前1R1C的长程适用性不足。** 测试段一步RMSE0.08598℃，持续基线0.09196℃；连续开环RMSE1.88526℃，持续基线0.79017℃；单段初始化的开环RMSE1.15514℃，持续基线0.62629℃。训练连续开环也有明显误差。全部训练、验证、测试指标、轨迹、残差和每个拟合初值都保存；没有按预测误差裁剪时段或移动功率。这个外部实验不构成武汉H/C实测标定，也不能证明武汉全年室温预测精度。

## 许可与原始文件身份

Fraunhofer机构仓储明示 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；选定原数据与由其变换的observations.csv、轨迹和图表保持该许可、作者与DOI署名。派生变更包括时钟转UTC、W转kW、房间面积加权温度、太阳辐射代理和独立拟合。发布者/作者没有对本项目方法或结果背书。

evidence/annex71_main_experiment.zip是原下载发布文件，SHA256在downloads.json；提取的两个XLSX按原ZIP成员CRC和尺寸核对，成员SHA在extracted_members.json。它们是原始**发布文件**，不等同未经处理的传感器原记录。规范6.2说明短时故障温度做线性插值，功率/流量置零，未提供逐行质量旗标，本轮无法恢复或排除这些行。O5曾有仿真功率补齐，本轮仅选N2，不读O5进行拟合。未知短时填补的数量如实列为缺口，不填“0个”。

DTU CTSM-R作者示例同样已下载，存在真实5分钟平均Ta、Ph、yTi、Ps，但例子ZIP没有许可声明，PDF正文和绘图的Ps单位还不一致；仅保留在本地发现证据中，不用它拟合或声称已核验许可。公开发布时须从交付包排除ctsm_*文件，直到确认许可。Strathclyde Annex58原许可明确CC BY4.0，但文件访问403，本轮未获得可分析文件。既有PH02/PH03/PH04本地研究PDF只读，未改动。

## 字段与聚合边界

完整逐字段依据见field_evidence_map.json；下载URL、日期、大小和SHA见evidence/downloads.json。十个*_110_AT为1.1m高度房间空气温度，按规范Figure9各房间地板面积加权（总165.75m²）。这是一份派生的传感器空间平均观测，不冒称传感器直接给出的全屋容积均温或时段末状态。

实际房间电加热与IHS列相加并从W转kW。部分房间共用一个加热器，发布者用安排的IHS量拆分两个列，本轮再合并以恢复总输入；不把两个列说成独立热表。电加热电功率按1倍变成房间热输入是本1R1C建模假设，未建加热器自身动态和辐射/对流分配。插座/风扇得热、通风能流、地面/阁楼蓄热和房间间传热没有显式模型。

现场天气是同时间标签的10分钟平均室外温度和辐射。太阳输入取水平全球与四向立面辐射最大值/1000作为kW/m²参考；系数为非负有效窗面积，约束上限16.77m²玻璃×0.62供应商SHGC=10.3974m²。窗数量与玻璃面积取规范Figure9/Table2，SHGC为供应商参考。这个代理不冒称实测透窗太阳得热；不建不透明围护太阳吸收。

## 时间和辨识定义

全部DATE标签完全相等后才合并；无重采样、无插补、无随机切分。源时钟固定UTC+1，转UTC减1小时。根据试验18:00开始而首行18:10，输出把标签解释为窗末，但发布者没有显式给出平均窗相位，所以该推断并非已确认的传感器时段末含义。动力学以同标签各变量为同一窗平均；不选择数据移位提高精度。

温度观测本身是区间平均。采用C·dT/dt=H·(Tout−T)+Q+A·I的常输入精确解，并在每窗对状态积分得到预测平均，避免把平均温度直接改名为末温。一步预测只用上一窗观测、上一窗及当前窗的已记录热/天气输入；持续开环只在首窗用观测初始化，随后整条轨迹仅传递模型状态；分段开环在每个训练/验证/测试段开始用前一窗观测初始化一次。基线按同信息模式保持温度。未来热量/天气是已经记录的条件输入，本次不是实际未来天气或控制预测。

analysis_plan.json在拟合前写入：所有11988行顺序60%/20%/余下切分（训练7192行，其中7191个预测目标；验证2397，测试2399）；结构固定1R1C，H>0、C>0、太阳系数有物理上限，无随机切分。参数只拟合训练一步残差SSE，4个确定性初值只按训练SSE选择，验证/测试不参与调参。H[0.02,1]kW/K与C[0.1,100]kWh/K是宽分析边界，不是实测给定值。

拟合得到H=0.139501735kW/K、C=5.773898947kWh/K、有效太阳面积1.781451734m²；均未碰边界。这些是此聚合与损失目标下的等效参数，不能作为武汉、或该试验房已获认证的真实构造物性。残差存在相关性，参数置信区间不作独立同分布保证。

## 复现与验证

工程根目录运行 `python scripts/validate_external_rc_benchmark.py`，读取缓存原文件、小规模SciPy拟合并在outputs/competition_20261001/C1_external写完整结果，最后才写manifest。首次提取若需ZIP方法9支持，可用已安装inflate64；本轮两个源XLSX均已提取并有CRC/SHA证据，正常复跑不需要重新下载。

`python -m pytest tests/test_external_rc_benchmark.py -q --basetemp=outputs/competition_20261001/C1_external/pytest_check` 验证来源身份、连续性/单位、坏数据拒绝、时间切分、无未来观测泄漏、训练拟合隔离、积分观测公式和全部误差独立重算。测试内少量解析夹具只检程序，不计为外部实验数据。

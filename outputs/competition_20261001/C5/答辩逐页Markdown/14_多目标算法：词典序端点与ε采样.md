# 第14页｜多目标算法：词典序端点与ε采样

## 正文建议

- 供热代码统一冷热总运营排放表达式；成本/碳词典序端点与ε采样按容差去重、去支配，工程前沿尚未准入。
- 已批准的公开数学补证：Mavrotas作者报告第4.1节，max f1＝x1，max f2＝3x1＋4x2；5x1＋4x2≤200，x1≤20，x2≤40。非负域依据原图解释。
- 用项目LinearMILP数值层和独立两阶段词典序包装实际求解；不等同HeatPlanningModel端点实现或完整AUGMECON复现。

## 讲稿要点

这份补证能核对数值层的词典序与ε采样，包括边界改变和不可行拒绝。它是公开数学算例；两阶段包装与供热模型接口的实现范围分开，不能把小LP结果外推为真实供热的精度、效率或收益。

## 对应评分与证据

多目标15分、工程10分：公开算例方法复现已准引用，供热工程多目标效果仍缺真实输入与结果。

[Effective implementation of the ε-constraint method in Multi-Objective Mathematical Programming problems](https://doi.org/10.1016/j.amc.2009.03.037)；[An improved version of the augmented ε-constraint method (AUGMECON2) for finding the exact Pareto set in Multi-Objective Integer Programming problems](https://mpra.ub.uni-muenchen.de/105034/1/MPRA_paper_105034.pdf)。阅读范围与限制见研究来源登记。

# 论文随附字体许可与版权信息

本目录仅补充当前论文三份既有 TTF 字体的许可与内部版权信息。本轮没有修改或替换字体。

字体许可采用官方 Noto CJK 仓库的 SIL Open Font License 1.1 文本；字体实际内部名称、版本、版权与校验码见 `FONT_LICENSE_MANIFEST.json`。

- Noto Sans SC：[官方许可](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)，随附文件 `OFL-NotoSansSC.txt`。
- Noto Serif SC：[官方许可](https://github.com/notofonts/noto-cjk/blob/main/Serif/LICENSE)，随附文件 `OFL-NotoSerifSC.txt`。

随附实际字体的内部版权声明：

- `NotoSansSC-Regular.ttf`：(c) 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
- `NotoSerifSC-Bold.ttf`：(c) 2017-2024 Adobe (http://www.adobe.com/).
- `NotoSerifSC-Regular.ttf`：(c) 2017-2024 Adobe (http://www.adobe.com/).

以上版权声明从随附字体的 name 表读取。实际内部 family 名称包含 Thin/ExtraLight，文件名沿用原交付；本次不据文件名推断其原始下载版次或字重来源。OFL 全文与这些实际版权声明应一并随字体分发。

本记录不证明本地字体与某份上游原始字体逐字节相同，也未追溯既往的字体实例化或转换过程。背景图和其他资产的许可不在此记录范围，不能据此声明模板原创或全部资产采用 OFL。
